## 文档要求

### 1. 当前契约文本

文档必须把核心契约写成：

- `aat:containsDirectly` 表达直接父子关系。
- `aat:childOrder` 表达同父局部顺序。
- `aat:documentOrder` 表达全局 preorder。
- source coordinate fields 表达 origin source location。
- IRI 不承载排序语义。

### 2. 删除旧契约

文档不得继续把 `aat:previousSibling` 写成当前核心契约。

如果必须提及，应放在迁移说明中：

```text
旧版本使用 aat:previousSibling 表达同父 sibling 链。当前版本移除该 predicate。消费者应使用 aat:childOrder 排序同父 children。
```

### 3. Breaking change 说明

release notes 必须说明：

- `aat:previousSibling` 被移除。
- `aat:childOrder` 被新增。
- `aat:documentOrder` 被新增。
- book-entry 下 heading order 来自 logical document tree。
- source coordinate 不再被视为合法 order fallback。
- 下游迁移方式是 `containsDirectly + childOrder + documentOrder`。

### 4. 不写入非核心承诺

文档不得把以下对象写成当前核心契约：

- `bookOutlineRaw`
- RDF List outline
- IRI lexical order
- TTL textual order
- source line fallback order

## 真实样例验证

使用真实大书样例生成 RDF12：

```bash
pnpm exec tsx src/cli.ts \
  /home/t103o/workbench/micheng-ts/projects/asciidoc-multi-book-workspace/templates/default-workspace/books/07-structured-writing-conventions/book.adoc \
  --mode book-entry \
  --document-root /home/t103o/workbench/micheng-ts/projects/asciidoc-multi-book-workspace/templates/default-workspace \
  --format rdf12
```

必须确认：

- `从源文档看结构` 的 `documentOrder` 位于 frontmatter 之后、第二部之前。
- `索引` 的 `documentOrder` 位于 backmatter 最后区域。
- `从源文档看结构` 不通过任何 predicate 指向 `索引` 作为 previous sibling。
- Graph 中不存在 `aat:previousSibling`。
- `containsDirectly` 不直接把 part 内 chapters 挂到 document title 下。
- 每个 parent 的 direct children 有连续 `childOrder`。

## 审核清单

审核者逐项检查：

### 对象完整性

- [ ] 核心对象是 ordered heading tree graph。
- [ ] 文档没有把渲染视图当成核心图事实。
- [ ] 文档没有把实现顺序写成对象定义。

### 字段准入

- [ ] 每个新增字段有明确消费者动作。
- [ ] `childOrder` 和 `documentOrder` 有不变量。
- [ ] `previousSibling` 不作为当前核心字段存在。

### 实现边界

- [ ] `startLine` 不参与 heading structure order。
- [ ] `relativePath` 不参与 book order。
- [ ] IRI 不参与 book order。
- [ ] Turtle output order 不参与 book order。

### 上游测试

- [ ] book-entry origin line collision fixture 存在。
- [ ] fixture 证明当前旧算法会失败。
- [ ] 新算法通过 fixture。
- [ ] source coordinate tests 仍证明 raw 回 origin file。

### 下游测试

- [ ] `ttl-graph-viz` 按 `childOrder` 排 contained children。
- [ ] `ttl-graph-viz` 不读 `previousSibling`。
- [ ] `ttl-graph-viz` 不用 source line fallback 修复 book order。
- [ ] 缺少 required order facts 时不会静默成功。

### 文档发布

- [ ] Bookshelf 文档已更新。
- [ ] README 或 public docs 已更新。
- [ ] CHANGELOG / release notes 标出 breaking change。
- [ ] 迁移路径明确。

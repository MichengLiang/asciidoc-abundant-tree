本目录是 `asciidoc-abundant-tree` 的书稿入口。

本目录的基本单位是书。每本书都有自己的 `book.adoc`，根目录提供统一依赖、统一构建和总入口。

公开 HTML 入口：link:https://michengliang.github.io/asciidoc-abundant-tree/[https://michengliang.github.io/asciidoc-abundant-tree/]

== 书目

* xref:books/06-rdf12-line-projection/book.adoc[AsciiDoc 标题切片到 RDF 1.2 投影规约]
* xref:books/07-rdf12-heading-projection-implementation-plan/book.adoc[RDF 1.2 标题投影图实现计划书]
* xref:books/08-rdf12-heading-projection-query-workflow/book.adoc[AsciiDoc 书稿 RDF 投影与 ARQ 查询教程]

== 书库范围

* 根目录提供统一 Asciidoctor 构建入口。
* `books/` 下每个一级子目录是一本文档书。
* `shared/` 只保留跨书共享属性。

== 构建入口

构建全部书稿：

[source,bash]
----
pnpm run build
----

[source,text]
----
- 建立 simple-book fixture：entry file、frontmatter、两个 chapter、nested include、backmatter glossary。
- simple-book/book.adoc 包含 document title、part heading、frontmatter include、chapter include、nested include、backmatter include 和 escaped include。

- book-entry acceptance tests 覆盖 mode、entry sourcePath、included heading、entry/chapter/nested relativePath、origin raw、xref coordinate、target coordinate、escaped include、same-line source scope。
- negative contract tests 覆盖 missing include、circular include、unsupported tag、unsupported lines、outside documentRoot、logical line count 与 line origin count 不一致。

- expected-fail 标记集中在 book-entry acceptance 和 negative test 文件顶部，并标明移除批次。

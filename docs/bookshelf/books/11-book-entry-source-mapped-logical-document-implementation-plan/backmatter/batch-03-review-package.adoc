=== 完成范围

[source,text]
----
- src/parser-core.ts 承担 shared parser core assembly：source surface projection、official projection、target merge、xref binding、AbundantDocument assembly。
- single-file public parser path 保持 readFileSync(sourcePath)、buildLineTable(source physical text)、adapter.loadFile(sourcePath)。
- book-entry public parser path 调用 buildLogicalSource，再以 logicalText 建立 parser surface line table。
- book-entry public parser path 调用 adapter.loadSource(logicalText)，不调用 adapter.loadFile(entryPath)。
- adapter 显式区分 loadFile(sourcePath) 与 loadSource(sourceText)；memory parse 入口不接收 sourcePath。
- book-entry 返回标准 AbundantDocument，mode 为 "book-entry"，sourcePath 为 resolved entry file path，sourceText 为 logicalText。
- parser core 对 book-entry logical input 不传 sourceSurfacePath，因此不把 logical text 伪装成 entry physical source file。
- parser-integration.test.ts 覆盖 included headings 进入 section tree、logical sourceText、book-entry mode、entry sourcePath、memory parse logical line alignment、book-entry 不依赖 include sourcemap。
- book-entry acceptance 中 parser core memory entry 相关 expected-fail 已移除；origin-aware recovery、public API/CLI、downstream 和 diagnostics 相关 expected-fail 保留到后续批次。
----

=== 完成范围

[source,text]
----
- 建立 src/book-entry 模块边界：model、diagnostics、path-boundary、include-resolution、logical-source-builder。
- LogicalSource 表达 entryPath、documentRoot、logicalText、lineOrigins 和 sourceFiles。
- LineOrigin 记录 logicalLine、absolutePath、relativePath、sourceLine。
- SourceFileRecord 记录 absolutePath、relativePath、text 和缓存的 LineTable。
- book-entry construction error codes 覆盖 include.missing-target、include.outside-document-root、include.cycle、include.unsupported-attrlist、logical-line-origin.count-mismatch、line-origin.source-file-missing、line-origin.source-line-out-of-range。
- builder 从 entry file 出发展开未转义 full-file include directive。
- escaped include 作为普通 source line 保留。
- include target 按 containing directive 所在文件目录解析。
- nested include 和 recursive include 展开进入 logical text。
- shared attributes include 展开进入 logical text，attribute line 的 sourceFiles 和 line origin 指向 shared attributes 文件。
- include cycle 使用 include stack 检测并返回 include.cycle。
- documentRoot boundary check 在读取 include target 文件前执行。
- source file table 以 absolutePath 去重，同一 absolutePath 在一次构造中最多读取一次。
- logical line origin 与 logical line 保持 1-based 连续顺序，支持 O(1) logical line 下标查找。
- assertLogicalDocumentInvariants 覆盖 logical line count、source file table reference、sourceLine range。
- book-entry acceptance 中 logical source builder 相关 expected-fail 已移除，parser core memory entry 相关 expected-fail 保留到 Batch 03+。
- book-entry negative test 中 logical-line-origin.count-mismatch 构造层 expected-fail 已移除，parser public dispatch negative contract expected-fail 保留到 Batch 07。
----

- RDF12 payload resources read `aat:relativePath` from the listing payload source layer.

- Projection-level source document provenance still points at the entry/source document relativePath.

- RDF12 downstream projection consumes only the public `AbundantDocument` and RDF12 options; it does not require a line origin table parameter.
- Book-entry RDF12 coordinate tests cover entry, chapter, nested include, xref edge, xref sourceHeading, missing-origin no-fallback, payload, provenance, and absence of `build/adoc` aggregate paths.

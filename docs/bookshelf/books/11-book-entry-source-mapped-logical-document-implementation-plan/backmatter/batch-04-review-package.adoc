=== 完成范围

[source,text]
----
- src/book-entry/origin-coordinate.ts 提供 logical line 到 line origin lookup、origin source file lookup、origin source span construction、origin raw recovery 和 recovery diagnostics。
- src/book-entry/source-scope-index.ts 提供 relativePath-aware source scope lookup；book-entry containing section 查找同时比较 occurrence relativePath 和 origin line range。
- book-entry section source layer 映射到 heading origin relativePath；heading raw 从 origin file line table 恢复，不从 logical text 切取。
- 打回修正后，book-entry recovery context 绑定到具体 `LineTable` 实例：`buildLineTable(source)` 消费一次 pending logical source 并写入 `WeakMap<LineTable, LogicalSource>`；同文本 single-file parse 和同文本不同 origin 的 book-entry parse 不共享 recovery context。
- 打回修正后，section heading raw/span 按 origin file heading-slice boundary 恢复，不再盲目延伸到 origin file EOF；同 origin 后续 block metadata/listing/table boundary 会截断 heading raw，跨 origin nested include heading 不截断 parent origin include directive raw。
- 第二次打回修正后，section heading raw/span 与 source scope containment 分离：public `section.source.raw/span` 仍表示 heading slice，book-entry containment 使用内部注册的 `SectionSourceScope` candidate。
- `src/source-surfaces.ts` 从 parser logical section interval 映射 same-origin source scope range，并注册到 `src/book-entry/source-scope-index.ts`；该 range 按 origin `relativePath` 与 origin line 匹配，不暴露为 public fake raw/source coordinate。
- xref occurrence 和 anchor occurrence sourceSpan/source layer 映射到 occurrence origin relativePath。
- target source layer 通过 section/listing/table/block source layer 携带 origin relativePath；顶层 sourceSpan 只保留兼容镜像。
- paragraph、listing 和 table source layers 映射到单一 origin file；listing contentSpan 映射到 origin content line range。
- cross-origin block span 产生 `source-recovery.cross-origin-block` diagnostic，且不输出 fake raw/source/sourceSpan。
- `source-recovery.logical-interval-unmapped` 和 `source-recovery.origin-line-missing` 覆盖无法映射 logical interval 或 origin line table 缺失的 recovery failure。
- single-file mode 保持原有 source surface 路径：没有 logical source recovery context 时继续使用 line-only `sectionByLine` 和 logical/physical single-file line table。
- Batch 04 acceptance 中 origin-aware recovery expected-fail 已移除；测试断言 entry/chapter/nested heading、xref、target 和 same-line scope 污染事实。
----

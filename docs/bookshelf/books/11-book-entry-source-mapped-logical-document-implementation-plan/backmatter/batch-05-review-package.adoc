=== 完成范围

[source,text]
----
- CLI args parser 支持 `--mode single-file|book-entry`，未知 mode 返回错误，不回落到 single-file。
- CLI args parser 支持 `--document-root <root>`，缺少值返回错误。
- 打回修正后，`--mode`、`--document-root` 和 `--format` 遇到下一个 token 仍是 flag 时均按缺少值处理。
- `--help` 输出包含 `--mode` 和 `--document-root`。
- CLI book-entry mode 调用 `parseAbundantTree({ sourcePath, mode: "book-entry", documentRoot })`。
- CLI book-entry mode 未显式传入 `--document-root` 时使用 `process.cwd()` 作为 documentRoot。
- CLI single-file/default mode 调用 single-file parser options；即使传入 `--document-root`，parser input construction 仍不展开 include。
- RDF12 CLI formats 继续消费同一个 `AbundantDocument`；single-file mode 的 `--document-root` 仍作为 RDF projection option。
- Library API 对 invalid JS 调用 `mode: "book-entry"` 且缺少 `documentRoot` 增加 runtime validation。
- 打回修正后，Library API 对 unsupported runtime `mode` 值抛出错误，不静默回落到 single-file。
- CLI 错误返回 stderr 且 stdout 为空；成功输出返回 stdout 且 stderr 为空。
- README 描述当前显式 book-entry public usage、CLI documentRoot 默认值和 single-file documentRoot 行为。
----

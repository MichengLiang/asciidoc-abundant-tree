== 前言

本书定义 RDF 1.2 行级投影器的工程实施序列。

`06-rdf12-line-projection` 定义 `AbundantDocument` 到 RDF 1.2 graph 的对象规约。本书定义兑现该规约的线性开发批次、上下文包、文件边界、验收条件、提交规则和审核打回条件。

本书的核心断言是：每个批次必须独立提交、独立审核、独立打回。前一批次没有提交 hash 和通过结论时，后一批次不得开始。

公共入口名固定为 `rdf12`。CLI 只增加 `--format rdf12`。TypeScript library 只暴露一个 `rdf12` 入口。`rdf12` 返回 RDF 1.2 projection graph，并提供 Turtle 1.2 文本。

本书使用中文叙事。RDF、Turtle、IRI、literal、triple term、reifier、selector、label、payload、provenance、graph、batch、review package 等术语在正文中保留英文形式或中英并列形式，以保持与规约、代码和审核记录之间的术语连续性。

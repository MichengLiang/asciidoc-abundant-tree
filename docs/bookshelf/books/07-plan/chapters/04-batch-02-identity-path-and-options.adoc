=== 输入事实

* `AbundantDocument.sourcePath` 是 source document 路径。
* `documentRoot` 是 relative path 基准。
* 默认 `baseIri` 是 `urn:aat:doc:`。
* `documentKey` 是 `sha256(relativePath)`。
* source digest 不进入 resource IRI。

=== 输出承诺

本批定义：

[source,typescript]
----
type Rdf12Options = {
	documentRoot: string;
	baseIri?: string;
	relationPrefixMap?: Record<string, string>;
	sourceText?: string;
	sourceDigest?: string;
};
----

Relative path 规则：

* 以 `documentRoot` 为基准。
* 使用 `/` 分隔符。
* 不包含 `..` 段。
* 不越出 `documentRoot`。

Resource IRI 规则：

[source,text]
----
documentKey      = sha256(relativePath)
resourceLocalId  = <kind>-l<startLine>-c<startColumn>-o<ordinal>
resourceIRI      = <baseIri><documentKey>#<resourceLocalId>
----

Block local id 省略 column。Occurrence local id 包含 column。

=== 实施任务

=== 测试任务

. 同一 input 生成同一 document key。
. 不同 relativePath 生成不同 document key。
. Windows separator 被转成 `/`。
. sourcePath 越出 documentRoot 抛错。
. 作者 ID 不进入 resource IRI。
. 标题文本不进入 resource IRI。
. source digest 不进入 resource IRI。
. 同 kind 同 line 同 column 冲突时 ordinal 稳定递增。

=== 验收标准

* relativePath 无 `..`。
* resource IRI 使用 `baseIri + documentKey + #localId`。
* `baseIri` 缺省值是 `urn:aat:doc:`。
* `sourceDigest` 缺省时不生成占位符。
* 本批不读取源文件内容，除非调用方通过 options 提供 `sourceText`。

=== 审核规则

审核者必须检查：

* resource IRI 没有作者字符串。
* relative path containment 使用 path 结构判断。
* source digest 不参与 IRI。
* documentRoot 是 required option。

=== 打回条件

出现以下任一情况，本批不通过：

* `section-basics` 出现在 section resource IRI 中。
* 标题文本出现在 resource IRI 中。
* relativePath 允许越出 document root。
* source digest 被拼入 structure resource IRI。

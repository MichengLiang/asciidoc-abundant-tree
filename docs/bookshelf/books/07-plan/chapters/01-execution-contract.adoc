[#execution-contract]
== 执行契约

本章定义本计划书的执行契约。所有批次章节均受本章约束。

=== 对象边界

本计划书的对象是 RDF 1.2 行级投影器的工程实施序列。

投影器对象由 xref:../06-rdf12-line-projection/book.adoc#object-boundary[对象边界]、xref:../06-rdf12-line-projection/book.adoc#projection-algorithm[投影算法] 和 xref:../06-rdf12-line-projection/book.adoc#invariants-and-acceptance[不变量与验收] 定义。本计划书不重新定义 RDF 投影器对象。本计划书只定义执行顺序、上下文包、文件边界、验收、提交和审核。

=== 公共入口

公共入口名是 `rdf12`。

CLI 公共表面：

[source,bash]
----
asciidoc-abundant-tree <file.adoc> --format rdf12
----

TypeScript public API 公共表面：

[source,typescript]
----
const projection = rdf12(document, {
	documentRoot: process.cwd(),
});

const graph = projection.graph;
const ttl = projection.ttl;
----

`rdf12` CLI 输出 Turtle 1.2 文本。该文本必须能被 RDF 1.2 Turtle parser 解析回 RDF graph。解析结果中 `rdf:reifies` 的 object 必须是 triple term。

`rdf12` TypeScript API 返回结构化 graph object 和 Turtle 1.2 文本。调用方不得为了取得 TTL 调用第二个 public entry。

=== 批次状态

批次状态使用受控集合：

[horizontal]
`未开始`:: 批次没有实现提交。
`执行中`:: 批次存在实现活动，尚未提交审核包。
`待审核`:: 批次提交 hash 和审核包已经产生。
`打回`:: 审核者拒绝通过该批次。
`通过`:: 审核者确认该批次满足本书验收条件。

批次状态记录在 xref:batch-status-ledger[批次状态台账]。状态台账只记录事实，不记录愿望、估计或口头进度。

=== 上游门槛

每个批次开始前必须满足以下门槛：

* 前一批次状态为 `通过`。
* 前一批次提交 hash 已写入状态台账。
* 当前工作树中不存在与本批无关的未提交修改。
* 执行者已经阅读本批上下文包列出的 06 号书原文和代码入口。

Batch 00 没有前置批次。Batch 00 开始前必须确认 `src/rdf12-projection/` 是正式实现目录，`spike/` 是研究证据目录。

=== 语言规则

批次章节使用规约语言。批次章节不得使用以下表达作为任务授权：

* 建议。
* 可以考虑。
* 最好。
* 尽量。
* 后续再说。
* 视情况。
* 基本完成。
* 差不多。

未确定对象不得进入实施任务。未确定对象必须登记为批次外事实、风险、相邻人工制品或打回项。

=== 文件提交规则

提交在内部 Git 仓库 `projects/asciidoc-abundant-tree` 中执行。

新文件必须先进入 Git index：

[source,bash]
----
git add <new-files>
----

每批提交使用 `git commit --only` 限定路径：

[source,bash]
----
git commit --only -m "<message>" -- <paths>
----

每批提交只包含本批文件。跨批文件、其它项目文件和无关格式化不得进入本批提交。

=== 审核包

每批完成后必须提交审核包。审核包格式见 xref:review-package-template[阶段审核包模板]。

审核包必须包含：

* 批次编号。
* 提交 hash。
* 修改文件列表。
* 本批完成范围。
* 本批未处理对象。
* 已运行命令。
* 命令结果。
* 规约检查清单。
* 审核结论。

没有提交 hash 的批次不得进入审核。没有审核通过结论的批次不得解锁下一批。

=== 全局打回条件

出现以下任一情况，当前批次必须打回：

* 投影层重新解析 AsciiDoc 源结构。
* 投影层打开跨文件 xref 指向的外部 `.adoc` 文件。
* 作者显式 ID、标题文本、生成 ID 或 xref display label 进入 resource IRI。
* 可回源 resource 缺少 `aat:relativePath`、`aat:startLine` 或 `aat:endLine`。
* `rdf:reifies` 的 object 是 string literal。
* 未绑定 selector 生成虚构 target node。
* 多义 selector 生成单一 target node。
* payload raw 被展开为业务 RDF graph。
* surface attribute 被升格为业务 predicate。
* CLI 暴露 `rdf`、`ttl` 或 `turtle` 作为公共 format。
* TypeScript public API 需要第二个 public entry 才能取得 TTL。
* 验收只比较 Turtle 字符串排版，不比较 graph 语义。

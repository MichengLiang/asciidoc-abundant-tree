== Batch 04：结构资源与 containment

=== 批次目标

本批从 `AbundantDocument.children` 创建 structure resources、source location triples 和 direct containment triples。

本批建立 node index。本批不生成 label catalog。本批不生成 xref relation triple。本批不生成 payload binding。

=== 输入事实

* `AbundantDocument.children` 是 containment 的唯一来源。
* `SectionNode` 投影为 `aat:Section`。
* `ParagraphNode` 投影为 `aat:Paragraph`。
* `ListingNode` 投影为 `aat:ListingBlock`。
* `TableNode` 投影为 `aat:TableBlock`。
* `AnchorOccurrenceNode` 投影为 `aat:AnchorTarget`。
* 每个可回源 structure resource 必须携带 relative path 和 line span。

=== 输出承诺

本批输出以下 resource type：

* `aat:Section`
* `aat:Paragraph`
* `aat:ListingBlock`
* `aat:TableBlock`
* `aat:AnchorTarget`

每个可回源 resource 必须输出：

* `aat:relativePath`
* `aat:startLine`
* `aat:endLine`

Listing resource 必须额外输出：

* `aat:metadataStartLine`
* `aat:metadataEndLine`
* `aat:contentStartLine`
* `aat:contentEndLine`
* `aat:listingStyle`
* `aat:language`
* `aat:sourceText`

Paragraph resource 必须输出 `aat:sourceText`。

Containment triples：

* document resource `aat:containsDirectly` top-level child resource。
* section resource `aat:containsDirectly` direct child resource。
* paragraph resource `aat:containsDirectly` direct xref/anchor child resource。
* table resource `aat:containsDirectly` direct xref/anchor child resource when children exist。

=== 测试任务

. `samples/reference-links.adoc` section resources 存在。
. section resources 有 relative path 和 line span。
. paragraph resources 有 source text。
. listing resource 有完整 span、metadata span、content span。
. table resource 有 line span。
. anchor target resource 有 line span。
. document direct children 来自 top-level `children`。
. section direct children 来自 section `children`。
. 不输出 containment transitive closure。

=== 验收标准

* `aat:containsDirectly` 只来自 `children`。
* 投影层不按 section level 重建 tree。
* listing 的完整范围、metadata 范围和 content 范围分离。
* 本批所有可回源 structure resource 均有 line span。

审核者必须检查：

* containment 没有传递闭包。
* structure projection 没有 source scanner。
* listing span triples 完整。
* node index 能供后续 label/xref 使用。

=== 打回条件

出现以下任一情况，本批不通过：

* 结构 resource 缺 `aat:relativePath`。
* 结构 resource 缺 `aat:startLine` 或 `aat:endLine`。
* containment 来自标题 level 推导。
* listing metadata/content span 被合并。

== Batch 00：基线与 RDF 1.2 spike 归档

=== 批次目标

本批归档 RDF 1.2 triple term 与 `rdf:reifies` spike 结论，固定正式实现的依赖事实和 public surface。

本批不实现正式投影器。本批不修改 `src/rdf12-projection/`。本批不修改 CLI。

=== 输入事实

* `n3@2.0.3` 可以写出 Turtle 1.2 `<<( ... )>>` triple term。
* `n3@2.0.3` 可以解析 Turtle 1.2 triple term，并把 reifier object 还原为 `Quad`。
* `N3.Store` 可以对重复 asserted relation triple 去重。
* `N3.Store` 可以保留多个 xref occurrence reify 同一个 relation triple。
* `n3@2.0.3` 没有内置 TypeScript declaration。
* `@types/n3@1.26.1` 可以用于 strict TypeScript，但其类型表面对 RDF 1.2 triple term 不完全自然。

=== 输出承诺

本批必须把以下结论写入工程记录：

* 正式实现使用项目自有 graph wrapper。
* N3 只作为 Turtle 1.2 serialization 和 parse-back test backend。
* 正式 public API 不暴露 N3 Store 作为核心 contract。
* CLI 新 format 名称是 `rdf12`。
* TypeScript public entry 名称是 `rdf12`。
* `rdf12` public API 返回 graph object 和 Turtle 1.2 text。

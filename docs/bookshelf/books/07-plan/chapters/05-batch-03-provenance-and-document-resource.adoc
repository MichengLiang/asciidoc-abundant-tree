== Batch 03：provenance 与 document resource

=== 批次目标

本批创建最小 `rdf12` projection 入口，并生成 provenance resources 和 document resource。

本批不投影 section、paragraph、listing、table、xref、attribute 或 payload。

=== 输入事实

* Projection graph 必须包含 source document entity。
* Projection graph 必须包含 projection entity。
* Projection graph 必须包含 projection activity。
* Projection graph 必须包含 `AbundantDocument` entity。
* Document resource 表示 source document 的结构根。
* Source document entity 表示来源文件。

=== 输出承诺

本批创建内部入口：

[source,typescript]
----
function projectAbundantDocumentToRdf12(
	document: AbundantDocument,
	options: Rdf12Options,
): Rdf12Projection
----

`Rdf12Projection` 至少包含：

[source,typescript]
----
type Rdf12Projection = {
	graph: Rdf12Graph;
	prefixes: Rdf12PrefixMap;
	relativePath: string;
	documentIri: string;
	sourceDocumentIri: string;
	projectionIri: string;
};
----

Provenance graph 必须包含：

* `source-doc a prov:Entity, aat:AsciiDocSourceDocument`。
* `source-doc aat:relativePath ...`。
* 可选 `source-doc aat:sourceDigest ...`。
* `projection a prov:Entity, aat:RdfProjection`。
* `projection prov:wasDerivedFrom source-doc`。
* `projection prov:hadPrimarySource source-doc`。
* `projection prov:wasGeneratedBy projection-activity`。
* `projection dcterms:source source-doc`。
* `projection-activity a prov:Activity, aat:ProjectionActivity`。
* `projection-activity prov:used source-doc`。
* `projection-activity prov:used abundant-document`。
* `abundant-document a prov:Entity, aat:AbundantDocument`。
* `abundant-document prov:wasDerivedFrom source-doc`。

Document resource 必须包含：

* `rdf:type aat:AsciiDocDocument`。
* `aat:relativePath`。

=== 实施任务

. 创建 `Rdf12Projection` 类型。
. 创建 internal projector function。
. 创建 source document entity IRI。
. 创建 projection entity IRI。
. 创建 projection activity IRI。
. 创建 abundant document entity IRI。
. 创建 document resource IRI。
. 写入 provenance triples。
. 写入 document resource triples。

=== 测试任务

. 空 `children` document 生成基础 graph。
. source document entity 和 document resource IRI 不相等。
. source digest 缺失时 graph 不含 `aat:sourceDigest`。
. source digest 存在时 graph 含 `aat:sourceDigest`。
. projection entity 含 `prov:hadPrimarySource`。
. projection activity `prov:used` source document 和 abundant document。

=== 验收标准

* 所有 provenance required triples 存在。
* document resource 不参与 PROV-O source identity 混用。
* 本批不生成 structure child resource。
* 本批不生成 label resource。

=== 审核规则

审核者必须检查：

* source document entity 与 document resource 分离。
* source digest 缺失时没有占位符。
* PROV-O predicates 使用 06 号书规定名称。

=== 打回条件

出现以下任一情况，本批不通过：

* `source-doc` 与 `document` 使用同一 IRI。
* `projection` 缺 `prov:hadPrimarySource`。
* `projection-activity` 缺 `prov:used abundant-document`。
* 本批开始投影 section 或 xref。

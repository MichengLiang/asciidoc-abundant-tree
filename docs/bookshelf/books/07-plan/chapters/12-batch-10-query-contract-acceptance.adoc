=== 输入事实

* 查询者通过 label catalog 定位 resource。
* 查询结果必须返回 resource、relative path 和 line span。
* Relation reifier 必须定位 xref occurrence evidence。
* Payload query 必须返回 full span 和 content span。

=== 输出承诺

本批验收覆盖以下查询类型：

* 按 `aat:AddressLabel` 查 resource。
* 按 `aat:TitleLabel` 查 section。
* 查 section 内 direct block。
* 查 xref occurrence。
* 查某 section 发出的 xref。
* 查未绑定 selector。
* 查 relation reifier。
* 查 surface attribute。
* 查 payload。
* 按 file 和 line 查覆盖结构。

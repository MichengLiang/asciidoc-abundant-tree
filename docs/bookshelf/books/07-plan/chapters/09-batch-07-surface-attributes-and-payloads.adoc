== Batch 07：surface attribute 与 payload block

=== 批次目标

本批投影 surface attribute、payload block、node payload binding 和 xref payload binding。

本批不解释 payload raw 内部格式。本批不生成业务 RDF graph。

=== 输入事实

* Metadata attrlist 字段投影为 `aat:SurfaceAttribute`。
* Xref ordinary named attributes 投影为 `aat:SurfaceAttribute`。
* Xref `rel` 和 `payload` 是控制字段。
* Payload block 是具有 `payload` 或 `xref-payload` role 的 block。
* Payload raw 是 opaque source text。

=== 输出承诺

SurfaceAttribute resource 必须输出：

* `rdf:type aat:SurfaceAttribute`
* `aat:name`
* `rdf:value`
* `aat:relativePath`
* `aat:startLine`
* `aat:endLine`

Metadata attribute 通过 `aat:hasAttribute` 连接到所属 structure resource。

Xref ordinary attribute 通过 `aat:hasAttribute` 连接到 xref occurrence resource。

PayloadBlock resource 必须输出：

* `rdf:type aat:PayloadBlock`
* `aat:payloadKind`
* `aat:relativePath`
* `aat:startLine`
* `aat:endLine`
* `aat:contentStartLine`
* `aat:contentEndLine`
* `aat:sourceText`
* data format 存在时输出 `aat:dataFormat`。
* address label

Node payload binding：

* Unique `forSelector` binding creates `node aat:hasPayload payload`。
* Unique `forSelector` binding creates `payload aat:payloadOf node`。
* Unbound or ambiguous `forSelector` creates no payload binding relation。

Xref payload binding：

* Unique `payloadSelector` binding creates `xref aat:hasPayload payload`。
* Xref payload attaches to xref occurrence resource。
* Xref payload does not attach to source node or target node。

. 实现 xref payload selector binding。

=== 测试任务

. `kind=policy` 生成 SurfaceAttribute。
. `status=active` 生成 SurfaceAttribute。
. `weight=0.8` 生成挂在 xref occurrence 上的 SurfaceAttribute。
. `rel=depends-on` 不生成 ordinary SurfaceAttribute。
. `payload=rel-delivery-capacity` 不生成 ordinary SurfaceAttribute。
. Payload block 具有 `aat:PayloadBlock` 类型。
. Payload raw 保存为 `aat:sourceText` literal。
. Payload JSON 字段不生成 RDF triples。
. Node payload 只在 `forSelector` 唯一绑定时生成 binding。
. Xref payload 只在 payload selector 唯一绑定时连接到 xref occurrence。
. Unbound payload selector does not create fake binding。

=== 验收标准

* 所有 surface attribute 都有 source location。
* Payload block 有 full span 和 content span。
* Payload ID 是 address label，不是 resource identity。
* Payload raw 保持 opaque text。
* 控制字段不重复生成为 ordinary attributes。

=== 打回条件

出现以下任一情况，本批不通过：

* payload JSON 字段进入 RDF graph。
* xref payload 连接到 relation endpoint。
* SurfaceAttribute 缺 line span。
* Payload ID 进入 payload resource IRI。

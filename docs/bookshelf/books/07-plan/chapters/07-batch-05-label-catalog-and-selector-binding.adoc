=== 输入事实

* Label 是源文档表面中的可显示、可寻址或可查询字符串。
* Selector 是 occurrence 或 binding 字段中用于寻找 target resource 的字符串。
* Label 和 selector 都不是 resource identity。
* `TargetNode` 是 selector binding 的辅助 catalog 条目。
* `TargetNode` 不生成独立 target resource。

=== 输出承诺

本批输出 label class：

* `aat:TitleLabel`
* `aat:BlockTitleLabel`
* `aat:AddressLabel`
* `aat:GeneratedAddressLabel`
* `aat:AnchorLabel`
* `aat:ReftextLabel`
* `aat:XrefDisplayLabel`
* `aat:RoleLabel`

每个 label resource 必须输出：

* `rdf:value`
* `aat:relativePath`
* `aat:startLine`
* `aat:endLine`

所属 resource 必须通过 `aat:hasLabel` 指向 label resource。

Selector binding 规则：

. selector 与 label catalog 中一个 label value 唯一匹配时，selector 绑定到该 label 所属 resource。
. selector 没有匹配时，selector 保留为 literal。
. selector 匹配多个 resource 时，selector 保留为 literal，并输出 candidate nodes。

=== 验收标准

* Label resource 均有 `rdf:value`。
* 可回源 label resource 均有 line span。
* `TargetNode` 不成为 projection resource。
* selector binding 不执行 dead link 判断。
* selector binding 不读取外部文件。

=== 审核规则

审核者必须检查：

* label 与 resource identity 分离。
* selector 多匹配路径没有 target node。
* `TargetNode` 只补充 catalog。
* label source location 来自输入对象字段。

=== 打回条件

出现以下任一情况，本批不通过：

* label value 出现在 structure resource IRI 中。
* `TargetNode` 被投影成独立 resource。
* 多义 selector 选择第一个 candidate。
* label resource 缺 source location。

=== 输入事实

* 每个 `XrefOccurrenceNode` 必须生成 `aat:XrefOccurrence` resource。
* Xref occurrence 保留 raw、target selector、display label、attributes、source span 和 official evidence。
* `containingSectionId` 是 source selector。
* `target` 是 target selector。
* Source node、predicate IRI 和 target node 都确定时，projection graph 生成 relation triple 和 reifier。

=== 输出承诺

Xref resource 必须输出：

* `rdf:type aat:XrefOccurrence`
* `aat:syntax`
* `aat:raw`
* `aat:targetSelector`
* `aat:relativePath`
* `aat:startLine`
* `aat:endLine`
* `sourceSpan` 存在时输出 `aat:startColumn` 和 `aat:endColumn`。
* `containingSectionId` 存在时输出 `aat:sourceSelector`。
* source binding 唯一时输出 `aat:sourceNode`。
* target binding 唯一时输出 `aat:targetNode`。
* target binding 多义时输出 `aat:candidateNode`。
* official href 存在时输出 `aat:officialHref`。
* official resolved id 存在时输出 `aat:officialResolvedId`。
* official resolved type 存在时输出 `aat:officialResolvedType`。
* official reftext 存在时输出 `aat:officialReftext`。
* `rel` 存在时输出 `aat:rawRel`。
* `payload` 存在时输出 `aat:payloadSelector`。

Display label 必须生成 `aat:XrefDisplayLabel`。

Predicate mapping：

. no `rel` -> `aat:references`。
. absolute IRI -> that IRI。
. known CURIE -> expanded IRI。
. ordinary token -> `rel:` namespace IRI-safe encoding。
. unmappable value -> preserve `aat:rawRel` and do not generate relation triple。

Relation rule：

. source node、predicate IRI 和 target node 都存在时，assert relation triple。
. 成功生成 relation triple 的 xref resource 使用 `rdf:reifies` 指向对应 triple term。
. duplicate asserted relation triple is stored once。
. multiple xref resources can reify the same triple term。

=== 测试任务

. `<<3. 核心引擎设计>>` 生成 xref occurrence resource。
. 该 resource 保留 `targetSelector = "3. 核心引擎设计"`。
. 该 resource 默认使用 `aat:references`。
. 该 xref 绑定 source section 和 target section。
. graph 包含 asserted relation triple。
. xref resource `rdf:reifies` object 是 triple term。
. interdocument xref 不生成 local target node。
. unresolved xref 不生成 relation triple。
. multi-binding xref 输出 candidate nodes，不输出 target node。
. `rel=depends-on` 映射到 `rel:depends-on`。
. `payload=...` 输出 `aat:payloadSelector`。
. `rel` 和 `payload` 不作为 ordinary surface attributes。

=== 验收标准

* 每个 input xref occurrence 都有 xref resource。
* 所有 xref resource 有 relative path 和 line span。
* `rdf:reifies` 指向 triple term。
* official evidence 不覆盖 raw target selector。
* relation triple 只在 source、predicate、target 全部确定时生成。

=== 审核规则

审核者必须检查：

* Reifier object 是 graph triple term。
* Unbound selector 没有 target node。
* Multi-binding selector 没有 single target node。
* `rel` mapping 没有业务语义判断。
* Xref attribute 控制字段与 ordinary attribute 分离。

=== 打回条件

出现以下任一情况，本批不通过：

* `rdf:reifies` object 是 string literal。
* target unresolved 时生成 relation triple。
* source binding 不唯一时生成 relation triple。
* official evidence 覆盖 raw target。
* `rel` 被解释成业务 class。

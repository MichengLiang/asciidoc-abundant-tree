== Batch 09：public `rdf12` API 与 CLI

=== 批次目标

本批暴露唯一 public `rdf12` entry，并把 CLI `--format rdf12` 接入 Turtle 1.2 输出。

本批不增加 `rdf`、`ttl` 或 `turtle` public format。

=== 输入事实

* Existing CLI supports `tree` and `json`。
* Existing TypeScript API exports parser and serializers。
* `rdf12` CLI output 是 Turtle 1.2 text。
* `rdf12` TypeScript entry 返回 graph object 和 TTL string。

=== 输出承诺

CLI public surface：

[source,bash]
----
asciidoc-abundant-tree <file.adoc> --format rdf12
----

TypeScript public surface：

[source,typescript]
----
import { parseAbundantTree, rdf12 } from "asciidoc-abundant-tree";

const document = parseAbundantTree({ sourcePath: "samples/reference-links.adoc" });
const projection = rdf12(document, {
	documentRoot: process.cwd(),
});

const graph = projection.graph;
const ttl = projection.ttl;
----

CLI `rdf12` document root rule：

* 默认 `documentRoot` 是 `process.cwd()`。
* Input source path 在 projection 前完成 resolve。
* Source path 位于 `documentRoot` 外部时，CLI 以 code 1 退出。

=== 实施任务

. Export `rdf12` from `src/index.ts`.
. Define `Rdf12Result` public type.
. Normalize `rdf12` options.
. In `rdf12`, project graph and serialize TTL.
. 添加 CLI format value `rdf12`。
. Update CLI usage text.
. Use `process.cwd()` as CLI document root.
. On projection error, return exit code 1 and stderr message.
. Update README CLI section.
. Update README library API section.

=== 验收标准

* `rdf12` 是唯一新增 public CLI format。
* `rdf12` 是唯一新增 public TypeScript entry。
* CLI `rdf12` stdout 是 Turtle 1.2。
* TypeScript caller obtains TTL from `rdf12` result without second public call.
* Existing public API remains compatible.

=== 审核规则

审核者必须检查：

* CLI 不接受 `rdf`、`ttl` 或 `turtle` format。
* `rdf12` public function returns graph and ttl.
* CLI uses existing `parseAbundantTree` once.
* CLI does not add a second AsciiDoc parser path.

=== 打回条件

出现以下任一情况，本批不通过：

* CLI accepts `--format rdf`。
* CLI accepts `--format ttl`。
* CLI accepts `--format turtle`。
* TypeScript caller 必须调用另一个 public function 才能取得 TTL。
* CLI `rdf12` output 是 JSON envelope 而不是 Turtle text。

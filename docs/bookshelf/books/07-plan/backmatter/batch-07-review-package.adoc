=== Scope

本批完成对象：

* metadata attrlist 字段投影为 `aat:SurfaceAttribute`。
* xref ordinary named attributes 投影为 `aat:SurfaceAttribute`。
* xref control fields `rel` 和 `payload` 不重复生成为 ordinary surface attributes。
* 具有 `payload` 或 `xref-payload` role 的 listing 投影为 `aat:PayloadBlock`。
* payload full line span、content line span、source text、data format 和 address label。
* node payload `forSelector` unique binding。
* xref payload selector unique binding，且只挂到 xref occurrence resource。
* helper-created label resource identity 不与既有 label 或同线 xref display label 碰撞。

本批未处理对象：

* payload raw 内部格式解释。
* 业务 RDF graph 生成。
* Turtle 1.2 serialization 与 roundtrip。
* public `rdf12` API 和 CLI。

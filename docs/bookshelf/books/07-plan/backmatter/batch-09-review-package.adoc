=== Contract Checklist

* [x] `rdf12` 是唯一新增 public TypeScript entry。
* [x] `rdf12(document, options)` 返回 graph 和 `ttl`，调用方不需要第二个 public function 取得 TTL。
* [x] `rdf12` normalizes options before projection。
* [x] CLI `rdf12` stdout 是 Turtle 1.2 text，不是 JSON envelope。
* [x] CLI help includes `--format tree|json|rdf12`。
* [x] CLI rejects unsupported formats and lists `rdf12`。
* [x] CLI rejects `--format rdf`。
* [x] CLI rejects `--format ttl`。
* [x] CLI rejects `--format turtle`。
* [x] CLI uses existing `parseAbundantTree` path and does not add a second AsciiDoc parser path。
* [x] CLI uses `process.cwd()` as document root for RDF projection。
* [x] CLI rejects RDF projection for source path outside document root。
* [x] Existing tree and json CLI behavior remains covered。
* [x] `src/parser.ts`、`src/inline-occurrence-scanner.ts` 和 `src/official-projector.ts` 未修改。

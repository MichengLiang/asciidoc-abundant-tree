=== 完成范围

[source,text]
----
- structure-projector.ts 的 public 结构输出收敛为 aat:Heading，不再输出 Paragraph、ListingBlock、TableBlock 或 AnchorTarget 结构 resource。
- heading local id 使用 heading-l<startLine>-o<ordinal>，不使用 headline、address label 或 generated label。
- 标题节点写入 aat:headline、aat:headingLevel、aat:addressLabel 或 aat:generatedAddressLabel。
- 标题节点写入 aat:relativePath、aat:startLine、aat:endLine、aat:headingLine、aat:metadataStartLine/EndLine、aat:contentStartLine/EndLine。
- heading-slice.ts 基于 AbundantDocument 的 section/source surface 字段生成普通 section 标题自身 aat:raw；document title heading 仅使用显式 Rdf12Options.sourceText 构建 source-lines 行表取得 root/preamble 闭区间 raw，不读取 document.sourcePath，不重新解析 AsciiDoc 结构。
- document title heading 以 kind=document-title 进入 node-index entries()，localId 为 heading-l1-o0，targetType 仍为 section，供 Batch 02 在同一 heading index 抽象下投影 root containment。
- 无 sourceText 时，document title heading raw 降级为可证明的 title 行，span 为 title 行闭区间，不虚构 preamble content span。
- projector.ts 将 normalized Rdf12Options.sourceText 显式传入 structure-projector.ts；测试 fixture 显式读取 sample 文本并作为 sourceText 传入。
- heading-projection.acceptance.test.ts 中 Batch 01 两个目标测试解除 expected-fail；Batch 02、Batch 04、Batch 05、Batch 06 和 Batch 07 仍保持 expected-fail。
----

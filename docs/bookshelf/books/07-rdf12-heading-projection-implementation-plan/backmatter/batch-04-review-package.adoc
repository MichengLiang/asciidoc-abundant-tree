=== 完成范围

[source,text]
----
- xref evidence resource type 从 aat:XrefOccurrence 迁移为 aat:XrefEdge。
- xref evidence local id 使用 xref-edge-l<line>-c<column>-o<ordinal>。
- xref edge evidence 使用 aat:sourceHeading、aat:targetHeading 和 aat:candidateHeading。
- xref rel control field 使用 aat:rel 保存原始 rel 字符串。
- xref display text 使用 aat:displayLabel literal，不创建 label resource 或 catalog entry。
- xref edge evidence 保留 aat:targetSelector、aat:raw、source span、syntax、official href/resolution evidence。
- source heading、target heading 和 predicate 均确定时生成主 relation triple。
- 主 relation triple 使用 rdf:reifies triple term 连接到 edge evidence。
- 缺省 rel 映射为 aat:references。
- token、CURIE 和 absolute IRI rel 继续通过 relation-predicate 语义映射。
- invalid rel 保留 aat:rel，不生成主 relation triple 或 reifier。
- unresolved target selector 保留 edge evidence 和 targetSelector，不生成 targetHeading 或主 relation triple。
- ambiguous target selector 输出全部 candidateHeading，不生成 targetHeading 或主 relation triple。
- relation triple subject/object 均为 heading node。
- heading-projection.acceptance.test.ts 中 Batch 04 xref edge/reifier 断言解除 expected-fail；Batch 05、Batch 06 和 Batch 07 仍保持 expected-fail。
----

=== 完成范围

[source,text]
----
- label catalog entry 收敛为 heading owner、labelKind 和 value。
- projectLabels 从 node-index entries() 建立 heading-only label catalog。
- document title headline 绑定到 document title heading IRI。
- section headline 绑定到对应 heading IRI。
- source ID 绑定为 addressLabel selector。
- Asciidoctor generated ID 绑定为 generatedAddressLabel selector。
- public graph 不再输出 TitleLabel、AddressLabel、GeneratedAddressLabel、BlockTitleLabel、AnchorLabel、ReftextLabel、XrefDisplayLabel 或 RoleLabel resource。
- public graph 不再输出 aat:hasLabel。
- selector binding 只通过 heading label catalog 返回 heading IRI。
- duplicate selector 返回全部 candidate headings，不选择第一个 candidate。
- unbound selector 保留 unresolved literal，不生成虚构 target。
- listing ID、table ID、inline anchor ID、xref display text、role、payload ID、raw text 和 heading IRI 不进入 selector label catalog。
- external xref selector 不触发外部文件读取。
- heading-projection.acceptance.test.ts 中 Batch 03 label/selector 断言为普通 passing test；Batch 04、Batch 05、Batch 06 和 Batch 07 仍保持 expected-fail。
----

[source,text]
----
- heading attrlist named attributes 投影为 heading node 上的直接 string literal 谓词。
- heading attrlist role tokens 投影为 heading node 上的 aat:role string literal。
- heading #id 继续投影为 aat:addressLabel，不投影为 aat:id。
- xref ordinary named attributes 投影为 xref edge evidence 上的直接 string literal 谓词。
- xref rel 控制字段继续只作为 aat:rel 和 relation predicate 选择输入，不生成普通属性资源。
- xref payload 控制字段继续只作为 aat:payloadSelector，不把 selector 字符串写入 aat:payload。
- public graph 不再创建 aat:SurfaceAttribute resource。
- public graph 不再输出 aat:hasAttribute。
- public graph 不再用 rdf:value 表达 field attributes。
- field-predicate 映射对简单合法字段名使用 aat:<fieldName>。
- field-predicate 映射对不安全字段名使用稳定 IRI-safe encoded local name。
- heading-projection.acceptance.test.ts 中 Batch 05 direct field assertion 解除 expected-fail；Batch 06 和 Batch 07 仍保持 expected-fail。

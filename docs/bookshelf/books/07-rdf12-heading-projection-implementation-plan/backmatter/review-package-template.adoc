[#review-package-template]
== 阶段审核包模板

每个批次完成后必须提交审核包。审核包是批次事实记录，不是进度汇报。

=== 批次信息

[horizontal]
批次编号:: `Batch NN`
批次名称:: `<批次标题>`
提交 hash:: `<git commit hash>`
执行者:: `<name>`
审核者:: `<name>`
审核状态:: `待审核`、`打回` 或 `通过`

=== 修改文件

[source,text]
----
src/rdf12-projection/...
test/rdf12-projection/...
docs/bookshelf/books/07-rdf12-heading-projection-implementation-plan/...
----

文件列表必须只包含本批提交中的路径。

=== 完成范围

本节列出本批已经实现并由测试覆盖的对象事实。

[source,text]
----
- <对象事实 1>
- <对象事实 2>
- <对象事实 3>
----

完成范围不得写入“基本完成”“大概完成”“后续完善”等状态词。

=== 未处理对象

本节列出本批边界外的对象。边界外对象必须指向后续批次或明确说明不属于本计划。

[source,text]
----
- <对象>：归属 Batch NN。
----

=== 已运行命令

[source,bash]
----
pnpm test -- ...
pnpm typecheck
----

命令必须是实际运行过的命令。不得把计划运行的命令写成本节内容。

=== 命令结果

[source,text]
----
<命令 1>: PASS
<命令 2>: PASS
----

失败命令必须保留失败输出摘要，并说明失败是否属于本批允许失败集合。

=== 规约检查清单

* 本批没有修改批次边界外文件。
* 本批没有引入全局打回条件。
* 本批测试覆盖了正向事实。
* 本批测试覆盖了必要负向事实。
* 本批 public graph 与 06 号书对象语言一致。

=== 审核结论

[horizontal]
结论:: `通过` 或 `打回`
理由:: `<对象级理由>`
后续动作:: `<下一批次或返工项>`

=== 完成范围

[source,text]
----
- payload listing 投影为 complex property object，不输出 aat:PayloadBlock public type。
- payload object 使用 source-coordinate resource identity，payload id 不进入 IRI。
- payload object 写入 aat:payloadId。
- 无 payload id 的 `.payload` / `.xref-payload` listing 不投影为 public payload object，也不参与 payload binding。
- node payload object 写入 aat:payloadKind "node"。
- xref payload object 写入 aat:payloadKind "edge"。
- payload object 写入 aat:format、aat:raw、aat:relativePath、aat:startLine、aat:endLine、aat:contentStartLine、aat:contentEndLine。
- node payload 保留 aat:forSelector。
- node payload 通过 heading node 的 aat:payload 连接。
- edge payload 通过 xref edge evidence 的 aat:payload 连接。
- edge payload 不连接 source heading 或 target heading。
- unbound 和 ambiguous node payload selector 保留 payload object，不连接 heading。
- missing 或 ambiguous xref payload selector 不连接 xref edge evidence。
- payload raw 保持 opaque，不展开 JSON 字段为 RDF predicate。
- public graph 不输出 aat:hasPayload 或 aat:payloadOf。
- payload object 不作为 heading，不参与 containsDirectly/previousSibling，不作为 xref targetHeading。
- heading-projection.acceptance.test.ts 中 Batch 06 payload assertion 解除 expected-fail。
----

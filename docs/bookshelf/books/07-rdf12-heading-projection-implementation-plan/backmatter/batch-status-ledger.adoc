=== 台账规则

* 批次提交产生后，提交 hash 必须写入本表。
* 审核包路径必须写入审核记录。
* 批次被打回时，审核记录必须写明打回对象和返工批次。
* 下一批次开始前，上一批次状态必须为 `通过`。

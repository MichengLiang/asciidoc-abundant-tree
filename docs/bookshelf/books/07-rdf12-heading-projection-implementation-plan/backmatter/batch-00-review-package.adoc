=== 目标差距说明

[source,text]
----
- 当前旧输出没有 aat:Heading 和 aat:XrefEdge，仍输出 aat:Section、aat:Paragraph、aat:ListingBlock、aat:SurfaceAttribute、aat:PayloadBlock 和 aat:XrefOccurrence。
- 当前 containsDirectly 仍连接 document、section、paragraph、listing 等旧结构资源；目标只允许标题节点之间的直接包含。
- 当前没有 aat:previousSibling，目标要求同父同级标题顺序。
- 当前 kind/status/owner/weight 通过 SurfaceAttribute 资源表达；目标要求直接 aat:kind、aat:status、aat:owner、aat:weight literal 谓词。
- 当前 payload 使用 PayloadBlock、aat:hasPayload、aat:payloadOf、aat:sourceText 和 aat:dataFormat；目标要求 heading 或 XrefEdge 上的 aat:payload 复杂属性对象，并使用 aat:raw、aat:format 和 aat:payloadKind。
- 当前 xref 边存在 rel:depends-on 和 rdf:reifies triple term，但 reifier 主体是 XrefOccurrence；目标 reifier 主体必须是 XrefEdge 边证据。
----

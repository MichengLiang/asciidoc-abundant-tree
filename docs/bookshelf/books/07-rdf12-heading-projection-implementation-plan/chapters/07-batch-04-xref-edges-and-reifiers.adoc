== Batch 04：Xref 边与 Reifier

=== 批次目标

本批把 xref occurrence 投影迁移为标题之间的关系边和边证据。本批输出主 relation triple、`aat:XrefEdge`、`rdf:reifies`、source heading、target heading、target selector、display label、rel、raw 和回源坐标。

本批不处理 xref 普通字段谓词。本批不绑定 payload。

=== 输入事实

xref 所在标题切片决定 source heading。xref target selector 绑定到唯一标题节点时决定 target heading。`rel` 决定关系谓词；没有 `rel` 时谓词是 `aat:references`。

边证据是关系边的属性承载面和回源证据。边证据不是标题节点。

=== 实施任务

. 将 xref resource type 从 `aat:XrefOccurrence` 改为 `aat:XrefEdge`。
. 将 local id 从 `xref-l<line>-c<column>-o<ordinal>` 保持或迁移为 `xref-edge-l<line>-c<column>-o<ordinal>`；若迁移，测试必须锁定新 local id。
. 将 `aat:sourceNode` 改为 `aat:sourceHeading`。
. 将 `aat:targetNode` 改为 `aat:targetHeading`。
. 将 `aat:rawRel` 改为 `aat:rel`。
. 保留 `aat:targetSelector`。
. 将 xref display text 写为 `aat:displayLabel` literal。
. 在 source、target、predicate 均确定时生成主 relation triple。
. 用 `rdf:reifies` 连接边证据到主 relation triple 的 triple term。
. 未绑定 target selector 时只保留边证据和 selector，不生成主 relation triple。
. 多义 target selector 时输出候选 heading，不生成主 relation triple。
. `rel` 无法映射合法 IRI 时保留 `aat:rel`，不生成主 relation triple。

=== 验收标准

* 公共图中不出现 `aat:XrefOccurrence`。
* relation triple 的 subject 和 object 均为 heading node。
* `rdf:reifies` 指向主 relation triple。
* `rel` 字段只选择谓词，不触发业务解释。
* display label 不是 target heading identity。

=== 审核规则

审核者必须检查边证据与标题节点集合分离。审核者必须检查未绑定和多义 selector 路径没有主 relation triple。

=== 打回条件

出现以下任一情况，本批不通过：

* `aat:XrefOccurrence` 仍作为公共类型输出。
* relation triple 的端点不是 heading node。
* `rdf:reifies` object 是 string literal。
* display label 参与 selector binding 或 resource identity。

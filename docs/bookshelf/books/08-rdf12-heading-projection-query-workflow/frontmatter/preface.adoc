[#preface]
== 前言

本书定义 AsciiDoc 书稿的 RDF 投影查询工作流。该工作流把书架构建出的聚合 adoc 投影为 RDF 1.2 Turtle，并使用 Apache Jena ARQ 查询标题结构、交叉引用网络、引用入度、引用出度、递归子树和审计事实。

大型书稿通常由多个章节文件组成。源文件适合写作和维护，HTML 适合人工阅读，全文搜索适合查找字符串。它们都不能单独提供稳定的标题图、交叉引用绑定、引用网络和结构化行号查询。RDF 投影把这些事实放入可查询图中，使作者能够用 SPARQL 提问。

本工作流的直接回源坐标指向聚合 adoc。聚合 adoc 是构建产物，不是原始拆分书稿。作者修改原始书稿时，应使用查询得到的 headline、selector、raw 片段和 line span 作为线索，再用文本搜索定位原始章节文件。

TTL 文件属于 build artifact。它可以被缓存、提交或删除，但它不作为手写源文件存在。源书稿或构建结果改变后，TTL 必须重新生成。

本书的操作链条从 xref:build-and-projection[构建与投影] 开始，经由 xref:query-environment[ARQ 查询环境] 执行查询，并在 xref:reading-and-editing-loop[阅读与修改闭环] 中回到源书稿维护。交叉引用网络的核心查询集中在 xref:xref-edge-queries[交叉引用边查询]、xref:xref-degree-queries[引用入度与出度查询] 和 xref:xref-neighborhood-queries[交叉引用邻域查询]。

本书使用中文叙事。AsciiDoc、RDF 1.2、Turtle、TTL、SPARQL、ARQ、heading、xref、selector、payload、raw、line span、build artifact 等术语在正文中保留英文形式或中英并列形式，以保持命令、查询和工程实现之间的术语连续性。

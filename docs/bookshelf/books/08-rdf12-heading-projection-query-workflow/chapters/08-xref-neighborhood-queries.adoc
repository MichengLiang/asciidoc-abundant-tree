[#xref-neighborhood-queries]
== 交叉引用邻域查询

交叉引用邻域是围绕一个标题的局部 xref 网络。它包含该标题发出的引用、指向该标题的引用，以及这些邻居继续连接到的标题。

交叉引用邻域查询服务章节脉络阅读。它回答一个标题如何连接到其它标题，以及其它标题如何回到它。

邻域查询依赖 xref edge evidence。单跳边表见 xref:xref-edge-queries[交叉引用边查询]，入度和出度统计见 xref:xref-degree-queries[引用入度与出度查询]。

=== 正向一跳邻域

正向一跳查询读取当前标题直接引用的目标标题：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?target ?targetHeadline ?targetStart ?raw ?edgeStart WHERE {
  ?root aat:addressLabel "<heading-label>" .
  ?edge a aat:XrefEdge ;
        aat:sourceHeading ?root ;
        aat:targetHeading ?target ;
        aat:raw ?raw ;
        aat:startLine ?edgeStart .
  ?target aat:headline ?targetHeadline ;
          aat:startLine ?targetStart .
}
ORDER BY ?edgeStart ?targetStart
----

该查询回答“这个标题把读者带向哪里”。

=== 反向一跳邻域

反向一跳查询读取直接引用当前标题的 source heading：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?source ?sourceHeadline ?sourceStart ?raw ?edgeStart WHERE {
  ?root aat:addressLabel "<heading-label>" .
  ?edge a aat:XrefEdge ;
        aat:sourceHeading ?source ;
        aat:targetHeading ?root ;
        aat:raw ?raw ;
        aat:startLine ?edgeStart .
  ?source aat:headline ?sourceHeadline ;
          aat:startLine ?sourceStart .
}
ORDER BY ?edgeStart ?sourceStart
----

该查询回答“哪些标题把读者带到这里”。

=== 正向两跳邻域

正向两跳查询读取当前标题引用的标题，以及这些标题继续引用的标题：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?first ?firstHeadline ?second ?secondHeadline ?firstStart ?secondStart WHERE {
  ?root aat:addressLabel "<heading-label>" .

  ?edge1 a aat:XrefEdge ;
         aat:sourceHeading ?root ;
         aat:targetHeading ?first .
  ?first aat:headline ?firstHeadline ;
         aat:startLine ?firstStart .

  ?edge2 a aat:XrefEdge ;
         aat:sourceHeading ?first ;
         aat:targetHeading ?second .
  ?second aat:headline ?secondHeadline ;
          aat:startLine ?secondStart .
}
ORDER BY ?firstStart ?secondStart
----

该查询显式展开两步。显式展开比复杂 property path 更适合教程，因为 `aat:XrefEdge` 是边证据资源，不是直接 heading-to-heading 谓词。

=== 反向两跳邻域

反向两跳查询读取引用当前标题的标题，以及引用这些标题的更远 source heading：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?near ?nearHeadline ?far ?farHeadline ?nearStart ?farStart WHERE {
  ?root aat:addressLabel "<heading-label>" .

  ?edge1 a aat:XrefEdge ;
         aat:sourceHeading ?near ;
         aat:targetHeading ?root .
  ?near aat:headline ?nearHeadline ;
        aat:startLine ?nearStart .

  ?edge2 a aat:XrefEdge ;
         aat:sourceHeading ?far ;
         aat:targetHeading ?near .
  ?far aat:headline ?farHeadline ;
       aat:startLine ?farStart .
}
ORDER BY ?nearStart ?farStart
----

该查询回答“哪些标题通过中间标题间接走到这里”。

=== 双向一跳邻域

双向一跳查询把入边和出边合并为局部邻居表：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?direction ?neighbor ?neighborHeadline ?edgeStart ?raw WHERE {
  ?root aat:addressLabel "<heading-label>" .
  {
    ?edge a aat:XrefEdge ;
          aat:sourceHeading ?root ;
          aat:targetHeading ?neighbor ;
          aat:startLine ?edgeStart ;
          aat:raw ?raw .
    BIND("out" AS ?direction)
  }
  UNION
  {
    ?edge a aat:XrefEdge ;
          aat:sourceHeading ?neighbor ;
          aat:targetHeading ?root ;
          aat:startLine ?edgeStart ;
          aat:raw ?raw .
    BIND("in" AS ?direction)
  }
  ?neighbor aat:headline ?neighborHeadline .
}
ORDER BY ?direction ?edgeStart
----

该查询适合在修改一个标题前查看它的引用上下文。

=== 子树向外引用

子树向外引用查询读取一个章节范围内的 source heading 指向范围外的 target heading：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?sourceHeadline ?targetHeadline ?start ?raw WHERE {
  ?root aat:addressLabel "<heading-label>" .
  ?root aat:containsDirectly* ?source .

  ?edge a aat:XrefEdge ;
        aat:sourceHeading ?source ;
        aat:targetHeading ?target ;
        aat:startLine ?start ;
        aat:raw ?raw .

  FILTER NOT EXISTS {
    ?root aat:containsDirectly* ?target .
  }

  ?source aat:headline ?sourceHeadline .
  ?target aat:headline ?targetHeadline .
}
ORDER BY ?start
----

该查询回答一个章节范围依赖哪些外部章节。

=== 外部指向子树

外部入边查询读取范围外标题指向范围内标题的 xref：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?sourceHeadline ?targetHeadline ?start ?raw WHERE {
  ?root aat:addressLabel "<heading-label>" .
  ?root aat:containsDirectly* ?target .

  ?edge a aat:XrefEdge ;
        aat:sourceHeading ?source ;
        aat:targetHeading ?target ;
        aat:startLine ?start ;
        aat:raw ?raw .

  FILTER NOT EXISTS {
    ?root aat:containsDirectly* ?source .
  }

  ?source aat:headline ?sourceHeadline .
  ?target aat:headline ?targetHeadline .
}
ORDER BY ?start
----

该查询回答哪些外部章节依赖当前章节范围。

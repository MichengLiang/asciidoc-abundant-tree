[#query-environment]
== ARQ 查询环境

ARQ 是本工作流的 SPARQL 查询执行器。ARQ 读取 TTL 数据文件和 SPARQL 查询文本，并输出表格化查询结果。

=== 基本命令

查询命令使用 `--data` 指向 TTL，并把 SPARQL 查询文本传给 `--query`：

[source,bash]
----
arq --data build/adoc/books/<book-id>.adoc.ttl --query <(cat <<'SPARQL'
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?level ?headline ?start ?end WHERE {
  ?h a aat:Heading ;
     aat:headingLevel ?level ;
     aat:headline ?headline ;
     aat:startLine ?start ;
     aat:endLine ?end .
  FILTER(?level <= 1)
}
ORDER BY ?start
SPARQL
)
----

查询文本使用 SPARQL。常用前缀如下：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>
PREFIX rel: <https://micheng.dev/ns/asciidoc-relation#>
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX prov: <http://www.w3.org/ns/prov#>
----

本书的推荐查询使用 bash here-doc 表面。该表面让查询文本和执行命令保持在同一个可复制单元中。

=== 查询动作分组

推荐查询按动作分组：

[source,text]
----
来源确认
标题定位
标题切片
结构范围
交叉引用边
引用入度
引用出度
交叉引用邻域
质量审计
----

动作分组提供阅读顺序。查询语句集不是投影器的一部分；它是作者使用投影图的工作台。

常用查询按动作分布在 xref:heading-location-and-slices[标题定位与切片查询]、xref:structural-scope-queries[结构范围查询]、xref:xref-edge-queries[交叉引用边查询]、xref:xref-degree-queries[引用入度与出度查询] 和 xref:quality-audit-queries[质量审计查询] 中。集中版本见 xref:query-library[查询语句集]。

=== 参数处理

here-doc 查询没有独立参数表面。查询文本可以直接写入目标 label 或 headline：

[source,sparql]
----
?root aat:addressLabel "<heading-label>" .
----

`<heading-label>` 是教程占位符，不是合法查询值。作者复制查询后，把该 literal 替换为当前书稿中的 address label。

=== 排序规则

标题查询和引用查询应显式排序。RDF graph 不承诺 triple 顺序，ARQ 查询结果也不应依赖数据文件排版顺序。

文档阅读查询通常按 `?start` 或 `?start ?col` 排序：

[source,sparql]
----
ORDER BY ?start ?col
----

度数查询通常按度数降序排序：

[source,sparql]
----
ORDER BY DESC(?inDegree) DESC(?outDegree) ?headline
----

排序是查询契约的一部分。缺少排序的查询不适合作为稳定教程查询。

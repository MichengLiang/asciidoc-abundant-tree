[#glossary]
== 术语表

source document:: 作为事实来源的 AsciiDoc 源文件。

heading projection graph:: 从 source document 派生出的 RDF 1.2 标题投影图。

heading node:: 由等号标题创建的 RDF resource。标题节点是标题投影图的唯一结构节点类型。

headline:: 标题文本，不包含标题等号标记。

heading slice:: 标题节点对应的连续源文本区域。该区域从标题头部 metadata 或标题行开始，到下一个标题切片起点之前结束。

heading raw:: 标题切片的源文本原文。

structure edge:: 标题节点之间的直接父子结构边。`aat:containsDirectly` 表达直接包含；同父局部顺序由 `aat:childOrder` 表达，全局 preorder 由 `aat:documentOrder` 表达。

xref edge:: 由标题切片中的交叉引用创建的非层级关系边。

xref edge evidence:: 保存 xref raw、source heading、target heading、target selector、属性、payload 和回源坐标的边证据 resource。

payload:: 归属于 heading node 或 xref edge evidence 的复杂属性值。payload 保存 payload kind、payload role、format、raw、绑定事实和回源坐标，不展开内部结构，不作为 heading node、structure edge endpoint 或 xref target heading。只有由 selector 显式指向的 payload block 才保存 source payload id。

payload block:: 源文档中承载 payload raw 的 listing block。payload block 通过 `for` 或 `forSelector` 成为节点 payload，或通过 source payload id 被 xref `payload` selector 选中成为边 payload。payload block 自身不创建 RDF 结构节点。

source payload id:: payload block 在源文档中的手动 ID。source payload id 是 selector binding fact，不是 payload object 的 RDF identity，也不是 payload role。边 payload 需要 source payload id；节点 payload 不要求 source payload id。

payload role:: payload block 的 role token。payload role 是作者与下游消费者约定的 schema 或 model label，例如 `banana` 或 `pear`。payload role 不决定 payload kind，不绑定 heading，不选择边 payload。

payload format:: payload block 的 source block language。`[source,json]` 的 payload format 是 `json`；`[source,yaml]` 的 payload format 是 `yaml`。

direct attribute predicate:: 由源文档 named attribute 映射得到的 `aat:<name>` 谓词。该谓词表达源文档表面字段，不触发业务解释。标题 `#id`、role token、xref `rel` 和 xref `payload` 是专门字段，不按普通字段谓词处理。

local target:: source document 内可由 AsciiDoc xref 寻址的 target catalog entry。local target 可以是 section、listing、table、block、inline anchor 或未知类型 target。

selector:: 用于绑定目标的字符串。xref target selector 和节点 payload binding marker 的非空值查询 heading projection label space；xref `payload` selector 查询 source payload id space。无值 node payload binding marker 不是 selector，它按 payload block 源位置归属 owning heading。

node payload binding marker:: listing block attrlist 中的 `for` 或 `forSelector` 字段。该字段的存在使 listing block 成为节点 payload；字段有非空值时，该值是 heading selector；字段无值时，payload block 按源位置归属 owning heading。

address label:: 标题投影图中可寻址到 heading node 的作者声明 label。address label 来自标题自身手动 ID，或来自归属到该标题切片的本地非标题 target ID。

generated address label:: 解析器为没有手动 ID 的标题恢复出的可寻址 label。

heading projection label space:: selector 绑定 heading node 时查询的 label 空间。该空间由 `aat:addressLabel`、`aat:generatedAddressLabel` 和 `aat:headline` 构成。

relative path:: 相对于投影调用方指定文档根目录的文件路径。

line span:: 使用 1-based line number 表示的源文件连续行范围。line span 是闭区间。

source span:: 使用 1-based line number 和 1-based Unicode code point column 表示的源文件行列范围。`start.column` 是 token 起始列；`end.column` 是 token 结束后的列位置。

triple term:: RDF 1.2 中作为 RDF term 使用的 triple。

reifier:: 使用 `rdf:reifies` 指向 triple term 的 resource。

provenance:: 描述投影图、投影活动和源文档之间来源关系的信息。

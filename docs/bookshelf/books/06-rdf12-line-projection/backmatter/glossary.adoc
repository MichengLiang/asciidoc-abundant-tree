[#glossary]
== 术语表

source document:: 作为事实来源的 AsciiDoc 源文件。

heading projection graph:: 从 source document 派生出的 RDF 1.2 标题投影图。

heading node:: 由等号标题创建的 RDF resource。标题节点是标题投影图的唯一结构节点类型。

headline:: 标题文本，不包含标题等号标记。

heading slice:: 标题节点对应的连续源文本区域。该区域从标题头部 metadata 或标题行开始，到下一个标题切片起点之前结束。

heading raw:: 标题切片的源文本原文。

structure edge:: 标题节点之间的结构边，包括 `aat:containsDirectly` 和 `aat:previousSibling`。

xref edge:: 由标题切片中的交叉引用创建的非层级关系边。

xref edge evidence:: 保存 xref raw、source heading、target heading、target selector、属性、payload 和回源坐标的边证据 resource。

payload:: 归属于标题节点或 xref edge evidence 的复杂属性。payload 保存 id、kind、format、raw 和回源坐标，不展开内部结构，不作为标题节点、结构边端点或 xref target heading。

direct attribute predicate:: 由源文档 named attribute 映射得到的 `aat:<name>` 谓词。该谓词表达源文档表面字段，不触发业务解释。标题 `#id`、role token、xref `rel` 和 xref `payload` 是专门字段，不按普通字段谓词处理。

local target:: source document 内可由 AsciiDoc xref 寻址的 target catalog entry。local target 可以是 section、listing、table、block、inline anchor 或未知类型 target。

selector:: xref target、节点 payload `for` 字段或 xref `payload` 字段中用于绑定目标的字符串。xref target 和节点 payload `for` 绑定标题投影 label 空间；xref `payload` 绑定 listing block 的手动 ID 以选择边 payload。

address label:: 标题投影图中可寻址到 heading node 的作者声明 label。address label 来自标题自身手动 ID，或来自归属到该标题切片的本地非标题 target ID。

generated address label:: 解析器为没有手动 ID 的标题恢复出的可寻址 label。

heading projection label space:: selector 绑定 heading node 时查询的 label 空间。该空间由 `aat:addressLabel`、`aat:generatedAddressLabel` 和 `aat:headline` 构成。

relative path:: 相对于投影调用方指定文档根目录的文件路径。

line span:: 使用 1-based line number 表示的源文件连续行范围。line span 是闭区间。

triple term:: RDF 1.2 中作为 RDF term 使用的 triple。

reifier:: 使用 `rdf:reifies` 指向 triple term 的 resource。

provenance:: 描述投影图、投影活动和源文档之间来源关系的信息。

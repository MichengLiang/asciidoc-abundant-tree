[#projection-algorithm]
== 投影算法

投影算法把 `AbundantDocument` 转换为 RDF 1.2 graph。算法必须是确定性的：同一输入对象、同一 document root、同一词表配置生成同一 RDF graph。

=== 输入参数

投影器至少接收：

[horizontal]
`document`:: `AbundantDocument`。
`documentRoot`:: relative path 的基准目录。
`baseIri`:: projection resource IRI 的 base。
`relationPrefixMap`:: `rel` CURIE 展开表。

`documentRoot` 决定 `relativePath`。`baseIri` 决定 resource IRI 前缀。`relationPrefixMap` 决定 xref `rel` 字段如何映射为 predicate IRI。

=== 输出对象

投影器输出 RDF 1.2 graph。该 graph 至少包含：

* source document entity。
* projection entity。
* projection activity。
* document resource。
* 结构 resources。
* label resources。
* surface attribute resources。
* xref occurrence resources。
* payload block resources。
* containment triples。
* 可确定 xref relation triples。
* xref reifier triples。

=== 转换顺序

投影器按以下顺序构造 graph：

. 计算 source document metadata。
. 创建 source document entity、projection entity 和 projection activity。
. 创建 document resource。
. 遍历 `AbundantDocument.children`，创建结构 resources，并识别 payload block resources。
. 为结构 resources 和 payload block resources 写入 relative path 和 line span。
. 从结构 resource、payload resource、title、ID、metadata 和 target catalog 生成 label resources。
. 建立 label catalog。
. 从 `children` 关系生成 `aat:containsDirectly`。
. 创建 xref occurrence resources。
. 绑定 xref source node。
. 绑定 xref target node。
. 映射 xref predicate IRI。
. 对绑定完整的 xref 生成 relation triple 和 reifier。
. 创建 surface attribute resources。
. 绑定 payload selectors。
. 输出 RDF graph。

该顺序保证 xref 和 payload binding 发生在 label catalog 建立之后。

=== Source Document Metadata

投影器从 `AbundantDocument.sourcePath` 和 `documentRoot` 得到 relative path。投影器从源文件内容或调用方提供的内容摘要得到 source digest。

输出：

[source,turtle]
----
:source-doc a prov:Entity, aat:AsciiDocSourceDocument ;
  aat:relativePath "samples/reference-links.adoc" ;
  aat:sourceDigest "sha256:..." .
----

投影器未取得 source text 或调用方提供的 content digest 时，`aat:sourceDigest` 缺失。relative path 不可缺失。

=== 结构遍历

投影器递归遍历 `AbundantDocument.children`。每个可识别 node kind 创建对应 resource。带有 payload role 的 block 在该阶段同时创建 payload block resource。

遍历时保存 parent-child 关系。该关系用于生成 `aat:containsDirectly`。

结构 resource 的 IRI 根据 <<resource-identity>> 生成。resource 的 `kind` 不得来自业务字段。

=== Label 生成

投影器从结构 resource 生成 label：

* title 字段生成 `aat:TitleLabel` 或 `aat:BlockTitleLabel`。
* source ID 生成 `aat:AddressLabel`。
* generated ID 生成 `aat:GeneratedAddressLabel`。
* anchor ID 生成 `aat:AnchorLabel`。
* reftext 生成 `aat:ReftextLabel`。
* role token 生成 `aat:RoleLabel`。

每个 label resource 连接到其所属 resource：

[source,turtle]
----
:section-l12-o0 aat:hasLabel :label-l12-title-o0 .
----

label catalog 由 label value 到所属 resource 的映射组成。同一 value 可以对应多个 resource。

=== Xref 投影

每个 `XrefOccurrenceNode` 创建 xref occurrence resource。

必备步骤：

. 写入 syntax、raw、target selector、line span。
. 生成 xref display label。
. 从 `containingSectionId` 绑定 source node。
. 从 `target` 绑定 target node。
. 从 attributes 中读取 `rel` 和 `payload` 控制字段。
. 映射 predicate IRI。
. 将普通 named attributes 转为 surface attribute。

source node、target node 和 predicate IRI 都存在时，输出 relation triple 和 reifier。

=== Payload 投影

投影器在结构遍历阶段已经为具有 payload role 的 block 创建 payload resource。本阶段写入 payload 专属字段并执行 selector binding。

步骤：

. 判断 role：`payload` 或 `xref-payload`。
. 写入 address label，并将 payload address label 纳入 label catalog。
. 写入 data format。
. 写入 source text。
. 写入完整 line span 和 content line span。
. 对 node payload 执行 `forSelector` binding。
. 对 xref payload 执行 `payloadSelector` binding。

payload binding 不完整时，payload resource 仍然存在。投影器不生成虚构绑定关系。

=== Determinism

投影器的排序规则必须稳定。相同输入产生相同 triple set。

稳定排序至少覆盖：

* children traversal order。
* label generation order。
* attribute ordinal。
* occurrence ordinal。
* payload ordinal。
* Turtle serialization order。

RDF graph 本身不依赖 triple 顺序。序列化顺序仍应稳定，以便测试和人工审查。

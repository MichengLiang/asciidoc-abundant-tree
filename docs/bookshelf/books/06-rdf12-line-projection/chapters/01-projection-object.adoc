== 投影对象

标题投影图是从单个 AsciiDoc 源文档导出的 RDF 1.2 图。该图描述标题节点、标题之间的结构边、标题切片中的交叉引用边，以及归属于节点或边的属性与 payload。

标题投影图的输入事实来自 source document 以及解析器恢复出的标题、标题层级、标题 metadata、xref occurrence、payload block 和 source location。投影器不重新解释 payload 内部结构，不执行业务 lint，不把普通段落或 block 提升为节点。

=== RDF 坐标

标题投影图使用 RDF 1.2 abstract data model。Turtle 是本书示例的可读序列化表面。Turtle 排版、前缀顺序和 triple 顺序不构成图语义。

本书使用以下命名空间：

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .
@prefix rel: <https://micheng.dev/ns/asciidoc-relation#> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix prov: <http://www.w3.org/ns/prov#> .
@prefix dcterms: <http://purl.org/dc/terms/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .
----

`aat:` 承载标题投影词表。`rel:` 承载由 xref `rel` 字段映射出的关系谓词。`rdf:` 承载 `rdf:type` 和 `rdf:reifies`。`prov:` 承载来源关系。`xsd:` 承载 typed literal。

=== 构成性对象

标题投影图只承诺两类结构查询资源：

[horizontal]
标题节点:: 由源文档中的等号标题创建。标题节点是文档结构、阅读、回源和递归查询的单位。
交叉引用边证据:: 由标题切片中的 xref 创建。边证据保存关系边的 raw、位置、属性、payload 和 RDF 1.2 reifier 关系。

标题投影图的其它结构事实归属于这两类资源。标题属性归属于标题节点。节点 payload 归属于标题节点。xref 普通属性归属于交叉引用边证据。xref payload 归属于交叉引用边证据。来源坐标归属于可回源的节点、边证据和 payload。

source document、projection 和 projection activity 是 provenance 资源。它们描述图从哪份源文件派生、由哪次投影活动生成。它们不属于标题节点集合，也不参与标题层级边。

payload 对象是复杂属性值。payload 对象保存 payload id、kind、format、raw 和回源坐标；它必须通过所属标题节点或交叉引用边证据进入查询，不作为独立的文档结构资源参与标题层级、兄弟顺序或 xref target 绑定。

=== 消费者动作

标题投影图服务以下动作：

* 按手动 ID 查找标题节点。
* 按 headline 查找标题节点。
* 读取标题节点自身的 raw 切片。
* 沿标题层级边递归读取子标题。
* 查看标题节点发出的交叉引用边。
* 读取边属性、边 payload 和 xref raw。
* 从查询结果回到源文件行范围。

公共图单位必须服务这些动作。不能服务这些动作的结构不进入标题投影图的核心对象。

=== 完整性

标题节点提供阅读单位。标题层级边提供递归阅读路径。交叉引用边提供作者显式写出的非层级关系。payload 提供复杂属性承载面。回源坐标提供读取和修改闭环。

这些对象共同构成标题投影图。标题投影图以标题为结构单位，并以标题切片、标题层级、交叉引用、payload 和回源坐标满足阅读、遍历、关系查询和源文件修改动作。

=== 排除边界

段落、listing、table、inline anchor、label、surface attribute 和 payload block 不创建标题节点。它们可以作为标题 raw、属性来源、payload 来源、绑定证据或回源事实出现。

payload 内部 JSON、YAML、TOML、XML 或其它格式不在标题投影图中展开。payload raw 的内部解释属于读取 payload 的下游消费者。

=== 来源与回源

标题投影图必须包含 source document entity、projection entity 和 projection activity。来源关系使用 PROV-O。

[source,turtle]
----
:source-doc a prov:Entity, aat:AsciiDocSourceDocument ;
  aat:relativePath "samples/structural-payload.adoc" ;
  aat:sourceDigest "sha256:..." .

:projection a prov:Entity, aat:HeadingProjection ;
  prov:wasDerivedFrom :source-doc ;
  prov:hadPrimarySource :source-doc ;
  prov:wasGeneratedBy :projection-activity .

:projection-activity a prov:Activity, aat:ProjectionActivity ;
  prov:used :source-doc .
----

`aat:relativePath` 使用 `/` 作为路径分隔符。该路径相对于调用方给定的 document root。每个可回源的 heading、xref edge evidence 和 payload 都必须保存相同的 `aat:relativePath` 以及自己的 line span。`aat:sourceDigest` 表示源文件快照；调用方提供 digest 或 source text 时必须输出该字段。

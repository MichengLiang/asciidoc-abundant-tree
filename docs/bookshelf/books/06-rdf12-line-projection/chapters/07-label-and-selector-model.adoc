[#label-and-selector-model]
== Label 与 Selector 模型

label 是源文档表面中的可显示、可寻址或可查询字符串。selector 是 occurrence 或绑定字段中用于寻找目标 resource 的字符串。label 和 selector 都是文档表面事实；二者均不构成 RDF resource identity。

=== Label Class

projection graph 使用受控 label class：

[horizontal]
`aat:TitleLabel`:: document title 或 section title。
`aat:BlockTitleLabel`:: listing、table 或其它 block 的标题。
`aat:AddressLabel`:: 作者显式 ID 或可寻址 anchor ID。
`aat:GeneratedAddressLabel`:: Asciidoctor generated ID。
`aat:AnchorLabel`:: anchor occurrence 的 ID。
`aat:ReftextLabel`:: official layer 或 anchor reftext 给出的引用文本。
`aat:XrefDisplayLabel`:: xref 方括号中的显示文本。
`aat:RoleLabel`:: attribute list 中的 role token。

label resource 必须包含 `rdf:value`。可回源 label 必须包含 `relativePath` 和 line span。

示例：

[source,turtle]
----
:section-l12-o0 a aat:Section ;
  aat:hasLabel :label-l12-title-o0 ;
  aat:hasLabel :label-l11-address-o0 .

:label-l12-title-o0 a aat:TitleLabel ;
  rdf:value "2. 基础概念" ;
  aat:relativePath "samples/reference-links.adoc" ;
  aat:startLine 12 ;
  aat:endLine 12 .

:label-l11-address-o0 a aat:AddressLabel ;
  rdf:value "section-basics" ;
  aat:relativePath "samples/reference-links.adoc" ;
  aat:startLine 11 ;
  aat:endLine 11 .
----

`rdfs:label` 是主要显示 label 的冗余表达。`rdfs:label` 不替代 label resource，因为 label resource 承载 label kind 和 source location。

=== Selector Class

selector 是绑定输入。projection graph 使用以下 selector 字段：

[horizontal]
`aat:targetSelector`:: xref raw target。
`aat:sourceSelector`:: xref 所在作用域的 source selector。
`aat:forSelector`:: node payload 的 `for` 字段。
`aat:payloadSelector`:: xref attribute 中的 payload 字段。
`aat:rawRel`:: xref attribute 中的 rel 字段。该字段是 predicate IRI 映射的输入，不参与 target resource binding。

selector 是 literal。selector 绑定到 projection resource，或保持未绑定状态。

示例：

[source,turtle]
----
:xref-l10-c60-o0 a aat:XrefOccurrence ;
  aat:targetSelector "3. 核心引擎设计" ;
  aat:sourceSelector "_1_引言" .
----

=== Label Catalog

label catalog 是 projection graph 的查询和绑定索引。投影器从结构 resource 产生 label，再用 label value 建立 catalog。

catalog 条目的输入来源包括：

* `SectionNode.title`。
* `SectionNode.ids` 与 `idOrigin`。
* `ListingNode.ids`。
* `ListingNode.title`。
* `TableNode.ids`。
* `TableNode.title`。
* `AnchorOccurrenceNode.ids`。
* `AnchorOccurrenceNode.reftext`。
* `TargetNode.id`。
* `TargetNode.title`。
* `TargetNode.asciidoctor.reftext`。
* metadata 中的 IDs、roles 和 titles。

`TargetNode` 不生成 target resource。`TargetNode` 补充 label catalog，使 target selector 绑定到已有结构 resource。

=== Selector Binding

selector binding 是 selector literal 与 label catalog 中 projection resource 的机械匹配。

规则：

. selector 与 catalog 中一个 label value 唯一匹配时，selector 绑定到该 label 所属 resource。
. selector 没有匹配时，selector 保留为 literal，不生成 target resource。
. selector 匹配多个 resource 时，selector 保留为 literal，并可输出 `aat:candidateNode`；投影器不任意选择一个 target node。

selector binding 不判断链接好坏。它只表达从当前文档表面能够机械恢复出的绑定关系。

=== 查询入口

label catalog 是编程 agent 的公共查询入口。查询者通过 label value 找到 resource，再读取 resource 的 `relativePath` 和 line span。

按 address label 查询：

[source,sparql]
----
SELECT ?node ?path ?start ?end WHERE {
  ?node aat:hasLabel ?label .
  ?label a aat:AddressLabel ;
         rdf:value "section-basics" .
  ?node aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

按 title label 查询：

[source,sparql]
----
SELECT ?node ?path ?start ?end WHERE {
  ?node aat:hasLabel ?label .
  ?label a aat:TitleLabel ;
         rdf:value "2. 基础概念" .
  ?node aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

该查询模式不依赖 resource IRI 的字符串形状。

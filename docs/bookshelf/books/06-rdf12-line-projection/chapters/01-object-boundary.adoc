[#object-boundary]
== 对象边界

本书定义一种从 `AbundantDocument` 到 RDF 1.2 行级结构图的选择性投影。该投影消费 `AbundantDocument` 已经恢复出的结构事实，并生成可查询、可回源、可重放的 RDF 图。

该投影的输入是 `AbundantDocument`，不是裸 AsciiDoc 文本。AsciiDoc 源文件由 `asciidoc-abundant-tree` 读取和恢复，恢复结果进入投影器。投影器不建立第二套 AsciiDoc parser，不把 Asciidoctor HTML 输出当作主输入，也不从源文件重新扫描结构表面。

该投影的输出是 RDF 1.2 graph。Turtle 是该 graph 的一种序列化形式。序列化文本不是投影对象的主身份；RDF triple、IRI resource、literal、triple term 和 reifier 构成投影对象的图结构。

=== 三层对象

该投影建立在三个对象之间：

[horizontal]
source document:: 作为事实来源的 `.adoc` 文件。
AbundantDocument:: 从 source document 恢复出的 TypeScript 结构对象。
projection graph:: 从 `AbundantDocument` 派生出的 RDF 1.2 图。

source document 是事实来源。`AbundantDocument` 是结构恢复层的公共契约。projection graph 是对该公共契约的图表达。

投影器不把 RDF 图写回 source document。投影器生成的 IRI resource 不进入作者维护的 AsciiDoc 表面。源文件重新解析以后，`AbundantDocument` 与 projection graph 均由当前源文件重新产生。

=== 选择性投影

选择性投影表示：只有 `AbundantDocument` 已经提供的结构事实才能进入 projection graph。投影器不得为缺失字段发明事实。

`AbundantDocument` 提供 section span 时，section resource 必须带行范围。`AbundantDocument` 提供 xref raw target 时，xref occurrence resource 必须带 target selector。`AbundantDocument` 未提供字符 offset 时，projection graph 不生成字符 offset。`AbundantDocument` 未提供 payload 内部结构时，projection graph 不展开 payload raw。

选择性投影不是任意裁剪。投影规则必须完整覆盖当前输入契约中的结构事实。一个字段是否进入图，由该字段是否服务结构查询、源文件定位、selector binding、关系 reification、attribute 表达或 payload 回源决定。

=== 职责边界

该投影器负责以下对象：

* source document 的相对路径和来源关系。
* `AbundantDocument` 中可回源结构资源的 RDF resource。
* section、paragraph、listing、table、anchor target、xref occurrence、payload block、label occurrence 和 surface attribute。
* 每个可回源 resource 的 `relativePath`、`startLine` 和 `endLine`。
* 标题、显式 ID、生成 ID、xref 显示文本、xref target、anchor ID 和 role token 的 label 或 selector 表达。
* `AbundantDocument.children` 派生出的 `aat:containsDirectly`。
* xref occurrence 派生出的 relation triple、RDF 1.2 reifier 和 occurrence evidence。
* attribute list 与 xref named attributes 派生出的 surface attribute。
* payload block 的 raw text、line span 和 selector binding。

该投影器不负责以下对象：

* AsciiDoc 语法重新解析。
* payload 内部 JSON、YAML、TOML、XML 或其它格式解释。
* 文档 lint。
* 死链接判断。
* 重复引用坏味道判断。
* 业务 class、状态机、组织实体、权重语义或领域关系解释。
* 跨文件 target 的存在性验证。
* `aat:containsDirectly` 的传递闭包物化。

这些对象属于后端查询、推理、lint、业务 schema 或专用转换器。projection graph 提供这些对象需要的结构事实，不替它们给出结论。

=== 主不变量

该投影遵守以下主不变量：

* 作者显式 ID、标题文本和 Asciidoctor generated ID 都是 label 或 selector，不是 RDF resource identity。
* RDF resource IRI 由投影器按照确定性规则生成。
* 每个可回源 resource 都携带 `relativePath`、`startLine` 和 `endLine`。
* xref occurrence 永远作为 resource 存在。
* xref selector 唯一绑定到 target node 时，projection graph 生成主 relation triple 和 reifier。
* xref selector 未绑定或多义绑定时，projection graph 保留 occurrence 和 selector，不生成虚构 target node。
* payload raw 作为 opaque text 保存。
* surface attribute 不升格为业务谓词。

本书各章分别定义这些不变量的输入字段、RDF 表面、绑定规则和验收口径。

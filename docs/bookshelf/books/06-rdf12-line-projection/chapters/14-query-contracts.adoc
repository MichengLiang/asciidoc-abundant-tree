[#query-contracts]
== 查询契约

本章定义 projection graph 的公共查询面。查询结果应返回 resource、relative path 和 line span，使编程 agent 能继续读取源文件。

=== 按 AddressLabel 查找 Resource

[source,sparql]
----
SELECT ?node ?path ?start ?end WHERE {
  ?node aat:hasLabel ?label .
  ?label a aat:AddressLabel ;
         rdf:value "engine-code" .
  ?node aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

该查询定位作者显式 ID 或 address label 对应的 resource。

=== 按 TitleLabel 查找 Section

[source,sparql]
----
SELECT ?section ?path ?start ?end WHERE {
  ?section a aat:Section ;
           aat:hasLabel ?label ;
           aat:relativePath ?path ;
           aat:startLine ?start ;
           aat:endLine ?end .
  ?label a aat:TitleLabel ;
         rdf:value "3. 核心引擎设计" .
}
----

该查询定位标题对应的 section resource。

=== 查找 Section 内的直接 Block

[source,sparql]
----
SELECT ?child ?kind ?path ?start ?end WHERE {
  ?section aat:hasLabel ?label .
  ?label rdf:value "section-basics" .
  ?section aat:containsDirectly ?child .
  ?child a ?kind ;
         aat:relativePath ?path ;
         aat:startLine ?start ;
         aat:endLine ?end .
}
----

该查询返回某 section 的直接 child resource。返回的行范围是 block 原文读取范围。

=== 查找 Xref Occurrence

[source,sparql]
----
SELECT ?xref ?selector ?path ?start ?end WHERE {
  ?xref a aat:XrefOccurrence ;
        aat:targetSelector ?selector ;
        aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

该查询返回源文档中的 xref occurrence。

=== 查找某 Section 发出的 Xref

[source,sparql]
----
SELECT ?xref ?selector ?target ?path ?start ?end WHERE {
  ?section aat:hasLabel ?sectionLabel .
  ?sectionLabel rdf:value "section-basics" .

  ?xref a aat:XrefOccurrence ;
        aat:sourceNode ?section ;
        aat:targetSelector ?selector ;
        aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .

  OPTIONAL { ?xref aat:targetNode ?target . }
}
----

该查询同时返回 raw selector 和已绑定 target node。

=== 查找未绑定 Selector

[source,sparql]
----
SELECT ?xref ?selector ?path ?start ?end WHERE {
  ?xref a aat:XrefOccurrence ;
        aat:targetSelector ?selector ;
        aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
  FILTER NOT EXISTS { ?xref aat:targetNode ?target . }
}
----

该查询返回没有 target node 的 xref occurrence。projection graph 不把该结果命名为 dead link；dead link 判断属于后端 lint。

=== 查找 Relation Reifier

[source,sparql]
----
SELECT ?xref ?path ?start ?end WHERE {
  ?xref a aat:XrefOccurrence ;
        rdf:reifies <<( ?source aat:references ?target )>> ;
        aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

该查询返回默认 `aat:references` relation 的 occurrence evidence。

=== 查找 Surface Attribute

[source,sparql]
----
SELECT ?node ?path ?start ?end WHERE {
  ?node aat:hasAttribute ?attr ;
        aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
  ?attr aat:name "kind" ;
        rdf:value "policy" .
}
----

该查询查找带有某个表面字段的 resource。字段名不需要成为 RDF predicate。

=== 查找 Payload

[source,sparql]
----
SELECT ?payload ?path ?start ?end ?contentStart ?contentEnd WHERE {
  ?payload a aat:PayloadBlock ;
           aat:relativePath ?path ;
           aat:startLine ?start ;
           aat:endLine ?end ;
           aat:contentStartLine ?contentStart ;
           aat:contentEndLine ?contentEnd .
}
----

该查询返回 payload block 的完整范围和内容范围。

=== 按文件与行查找结构

[source,sparql]
----
SELECT ?node ?kind ?start ?end WHERE {
  ?node a ?kind ;
        aat:relativePath "samples/reference-links.adoc" ;
        aat:startLine ?start ;
        aat:endLine ?end .
  FILTER (?start <= 35 && ?end >= 35)
}
----

该查询返回覆盖某一行的结构 resource。该结果提供从文件位置反查上下文结构的查询面。

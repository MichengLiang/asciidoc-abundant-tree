== 运力规则
------

该 source document 包含两个 section、一个 xref occurrence 和一个 xref payload block。

=== 结构事实

恢复层提供以下投影输入：

* section `配送策略`，行范围 1 到 11。
* section `运力规则`，行范围 12 到 13。
* address label `delivery-policy`。
* address label `capacity-rule`。
* xref occurrence，target selector 为 `capacity-rule`，display label 为 `运力规则`。
* xref attribute `rel=depends-on`。
* xref attribute `weight=0.8`。
* xref payload selector `rel-delivery-capacity`。
* payload block，完整行范围 6 到 10，content 行范围 9 到 9，address label 为 `rel-delivery-capacity`，data format 为 `json`，content 为 `{"reason":"risk-control"}`。

=== 查询结果

按显式 ID 查找 `capacity-rule`：

[source,sparql]
----
SELECT ?node ?path ?start ?end WHERE {
  ?node aat:hasLabel ?label .
  ?label a aat:AddressLabel ;
         rdf:value "capacity-rule" .
  ?node aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

结果：

[source,text]
----
node   = :section-l12-o0
path   = docs/policy.adoc
start  = 12
end    = 13
----

按 relation reifier 查找 xref occurrence：

[source,sparql]
----
SELECT ?xref ?path ?start ?end WHERE {
  ?xref a aat:XrefOccurrence ;
        rdf:reifies <<( :section-l1-o0 rel:depends-on :section-l12-o0 )>> ;
        aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

结果：

[source,text]
----
xref   = :xref-l4-c7-o0
path   = docs/policy.adoc
start  = 4
end    = 4
----

该结果可直接进入文件读取和 patch 回写循环。

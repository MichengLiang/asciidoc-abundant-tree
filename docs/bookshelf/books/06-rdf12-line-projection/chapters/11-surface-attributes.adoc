[#surface-attributes]
== Surface Attribute

surface attribute 表示源文档 attribute list 或 xref named attributes 中的表面字段。projection graph 使用 `aat:SurfaceAttribute` resource 表达该对象。

=== Attribute Resource

surface attribute resource 必须包含：

* `rdf:type aat:SurfaceAttribute`。
* `aat:name`。
* `rdf:value`。
* `aat:relativePath`。
* `aat:startLine`。
* `aat:endLine`。

示例：

[source,turtle]
----
:attr-l11-kind-o0 a aat:SurfaceAttribute ;
  aat:name "kind" ;
  rdf:value "policy" ;
  aat:relativePath "samples/reference-links.adoc" ;
  aat:startLine 11 ;
  aat:endLine 11 .
----

`aat:name` 是源文档中的字段名。`rdf:value` 是源文档中的字段值。投影器不根据字段名或字段值生成业务类型。

=== Node Attribute

metadata attribute list 中的字段连接到所属结构 resource：

[source,asciidoc]
----
[#delivery-policy, kind=policy, status=active]
== 配送策略
----

投影为：

[source,turtle]
----
:section-l2-o0 aat:hasAttribute :attr-l1-kind-o0 ;
  aat:hasAttribute :attr-l1-status-o0 .

:attr-l1-kind-o0 a aat:SurfaceAttribute ;
  aat:name "kind" ;
  rdf:value "policy" .

:attr-l1-status-o0 a aat:SurfaceAttribute ;
  aat:name "status" ;
  rdf:value "active" .
----

该投影表达“源文档表面有字段 kind=policy”。它不表达 section 是 `Policy` class。

=== Xref Attribute

xref named attributes 中的普通字段连接到 xref occurrence resource：

[source,asciidoc]
----
xref:capacity-rule[运力规则, weight=0.8]
----

投影为：

[source,turtle]
----
:xref-l4-c7-o0 aat:hasAttribute :attr-xref-l4-weight-o0 .

:attr-xref-l4-weight-o0 a aat:SurfaceAttribute ;
  aat:name "weight" ;
  rdf:value "0.8" .
----

edge attribute 属于 xref occurrence reifier，不属于 source node，也不属于 target node。

=== 控制字段

xref attributes 中的 `rel` 和 `payload` 是控制字段。它们使用专门谓词表达：

[horizontal]
`rel`:: 投影为 `aat:rawRel`，并参与 predicate IRI 映射。
`payload`:: 投影为 `aat:payloadSelector`，并参与 payload binding。

普通 `aat:SurfaceAttribute` 不重复表达这两个控制字段。该规则使关系控制面和普通表面字段保持分离。

=== 查询

查询者可以通过 `aat:SurfaceAttribute` 查找源文档表面字段：

[source,sparql]
----
SELECT ?node ?path ?start ?end WHERE {
  ?node aat:hasAttribute ?attr .
  ?attr aat:name "status" ;
        rdf:value "active" .
  ?node aat:relativePath ?path ;
        aat:startLine ?start ;
        aat:endLine ?end .
}
----

该查询不要求字段名成为 RDF predicate。

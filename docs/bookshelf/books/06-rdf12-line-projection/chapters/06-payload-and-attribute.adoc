[#payload-and-attribute]
== Payload 与属性

属性是节点或边上的直接谓词。payload 是节点或边上的复杂属性。

=== 直接属性谓词

标题 attrlist named attributes 直接投影为标题节点谓词。

[source,asciidoc]
----
[#delivery-policy.section, kind=policy, status=active, owner=ops]
== 配送策略
----

投影为：

[source,turtle]
----
:heading-l5-o0
  aat:kind "policy" ;
  aat:status "active" ;
  aat:owner "ops" .
----

xref 普通 named attributes 直接投影为边证据谓词。

[source,asciidoc]
----
xref:capacity-rule[运力规则, rel=depends-on, weight=0.8]
----

投影为：

[source,turtle]
----
:xref-edge-l8-c8-o0
  aat:rel "depends-on" ;
  aat:weight "0.8" .
----

属性谓词不触发业务解释。`aat:kind`、`aat:status`、`aat:owner`、`aat:weight` 只是源文档表面字段的 RDF 表达。下游消费者可以解释这些字段，也可以忽略这些字段。

字段名映射规则与标题节点属性一致。字段名进入 `aat:` 命名空间下的表面字段谓词。字段值保存为 string literal。`rel` 和 `payload` 是 xref 控制字段；`rel` 决定主 relation triple 的谓词，并可作为 `aat:rel` 保留；`payload` 选择边 payload，并保存为 `aat:payloadSelector`，不占用 `aat:payload`。

=== 节点 Payload

带有手动 ID 且声明 `for` 或 `forSelector` 字段的 listing block 表达节点 payload。绑定成功时，payload 作为该标题节点的 `aat:payload` 值。

节点 payload 的 `for` 字段只在标题投影 label 空间中绑定。绑定目标可以来自标题节点的 `aat:addressLabel`、`aat:generatedAddressLabel` 或 `aat:headline`。绑定失败或多义绑定时，payload 对象保留 `aat:forSelector` 和回源坐标，不连接到任何标题节点。`for` 字段不绑定到 payload 对象自身的 payload id、role、普通字段谓词或标题节点 IRI。

节点 payload 的 `for` 字段使用标题投影 label 空间。该空间中的 `aat:addressLabel` 包含归属到标题的本地非标题 target ID。`for` 字段仍不绑定到 payload 对象自身的 `aat:payloadId`，也不把 payload listing 提升为标题节点。

`.payload` role 不是节点 payload 的识别条件。role token 可以作为源文档表面语义投影为 `aat:role`，但节点 payload 绑定由 `for` 或 `forSelector` 字段决定。

payload format 来自 payload attrlist 的 `data` 字段。缺少 `data` 字段时，format 来自 source block 的 language。二者都缺失时，不输出 `aat:format`。

[source,asciidoc]
------
[#delivery-policy-payload, for=delivery-policy, data=json]
[source,json]
----
{
  "owner": {
    "team": "ops"
  }
}
----
------

投影为：

[source,turtle]
----
:heading-l5-o0 aat:payload [
  aat:payloadId "delivery-policy-payload" ;
  aat:payloadKind "node" ;
  aat:forSelector "delivery-policy" ;
  aat:format "json" ;
  aat:relativePath "samples/structural-payload.adoc" ;
  aat:startLine 10 ;
  aat:endLine 23 ;
  aat:contentStartLine 13 ;
  aat:contentEndLine 22 ;
  aat:raw "{\n  \"owner\": {\n    \"team\": \"ops\"\n  }\n}"
] .
----

=== 边 Payload

xref 的 `payload` 字段表达边 payload selector。带有匹配 ID 的 listing block 表达该边 payload。

边 payload 的绑定分两步。xref edge evidence 先用 `payload` 字段保存 `aat:payloadSelector`。投影器再用该 selector 匹配 listing block 的手动 ID。唯一匹配时，xref edge evidence 通过 `aat:payload` 连接该 payload 对象。未匹配或多义匹配时，边证据保留 `aat:payloadSelector`，不连接 payload 对象。

`.xref-payload` role 不是边 payload 的识别条件。role token 可以作为源文档表面语义投影为 `aat:role`，但边 payload 绑定由 xref 的 `payload` selector 和 listing block 的 ID 决定。

[source,asciidoc]
------
xref:capacity-rule[运力规则, rel=depends-on, payload=rel-delivery-capacity]

[#rel-delivery-capacity, data=json]
[source,json]
----
{"reason":"risk-control"}
----
------

投影为：

[source,turtle]
----
:xref-edge-l8-c8-o0 aat:payload [
  aat:payloadId "rel-delivery-capacity" ;
  aat:payloadKind "edge" ;
  aat:format "json" ;
  aat:raw "{\"reason\":\"risk-control\"}" ;
  aat:relativePath "samples/structural-payload.adoc" ;
  aat:startLine 25 ;
  aat:endLine 39 ;
  aat:contentStartLine 28 ;
  aat:contentEndLine 38
] .
----

边 payload 归属于交叉引用边证据。它不归属于 source heading，也不归属于 target heading。

边 payload 的 selector 语境与普通 xref target selector 语境不同。xref 的 `payload` 字段只选择边 payload；普通 xref target 指向同一个 listing block ID 时，该 ID 按本地非标题 target 规则归属为所属标题的 `aat:addressLabel`。payload 对象仍然是复杂属性值，不作为 relation triple 的端点。

=== Opaque Raw

payload raw 不展开为 RDF 图。JSON、YAML、TOML、XML 或其它 payload 格式内部字段不进入标题投影图。

payload 字段必须保存 payload id、payload kind、raw、relative path、完整 line span 和 content line span。payload format 按本章 format 规则输出。

payload 对象是复杂属性值。它不是标题节点，不参与 `aat:containsDirectly`、`aat:childOrder` 或 `aat:documentOrder`，不作为 relation triple 的端点。公共查询应通过所属标题节点或 xref edge evidence 取得 payload，而不是把 payload 当作独立文档节点遍历。

payload listing 的本地 target ID 成为所属标题节点的 address label。该 address label 只用于寻址标题节点，不改变 payload 对象的复杂属性身份。

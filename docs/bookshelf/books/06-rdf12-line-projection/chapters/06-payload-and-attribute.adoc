[#payload-and-attribute]
== Payload 与属性

属性是节点或边上的直接谓词。payload 是节点或边上的复杂属性。

=== 直接属性谓词

标题 attrlist named attributes 直接投影为标题节点谓词。

[source,asciidoc]
----
[#delivery.policy, status=active, owner=ops]
== 配送策略
----

投影为：

[source,turtle]
----
:heading-l5-o0
  aat:role "policy" ;
  aat:status "active" ;
  aat:owner "ops" .
----

xref 普通 named attributes 直接投影为边证据谓词。

[source,asciidoc]
----
xref:capacity[运力规则, rel=depends-on, weight=0.8]
----

投影为：

[source,turtle]
----
:xref-edge-l8-c8-o0
  aat:rel "depends-on" ;
  aat:weight "0.8" .
----

属性谓词不触发业务解释。`aat:role`、`aat:status`、`aat:owner`、`aat:weight` 只是源文档表面字段的 RDF 表达。下游消费者可以解释这些字段，也可以忽略这些字段。

字段名映射规则与标题节点属性一致。字段名进入 `aat:` 命名空间下的表面字段谓词。字段值保存为 string literal。`rel` 和 `payload` 是 xref 控制字段；`rel` 决定主 relation triple 的谓词，并可作为 `aat:rel` 保留；`payload` 选择边 payload，并保存为 `aat:payloadSelector`，不占用 `aat:payload`。`for` 和 `forSelector` 是节点 payload 控制字段；它们不作为普通 payload 内部字段投影。

=== Payload Object

payload object 是归属于标题节点或 xref edge evidence 的复杂属性值。payload object 的 RDF identity 由投影器生成；源文档中的手动 ID 只在 selector 需要指向 payload block 时成为绑定事实。

payload object 保存以下事实：

[horizontal]
`aat:payloadKind`:: payload 归属种类。节点 payload 使用 `node`；边 payload 使用 `edge`。
`aat:role`:: payload block 的 role token。该值是作者与下游消费者约定的 schema 或 model label。
`aat:format`:: payload block 的 source block language。
`aat:raw`:: payload body 原文。
`aat:relativePath`、`aat:startLine`、`aat:endLine`:: payload block 的完整源文件行范围。
`aat:contentStartLine`、`aat:contentEndLine`:: payload body 的源文件行范围。

payload raw 不展开为 RDF 图。payload role 和 payload format 只为下游解释 raw 提供源表面线索；标题投影器不执行 schema validation，不把 payload 内部字段投影为 RDF 谓词。

=== 节点 Payload

声明 `for` 或 `forSelector` 字段的 listing block 表达节点 payload。`for` 字段是节点 payload binding marker。该字段的存在使 listing block 成为节点 payload；字段有值时按 heading selector 绑定，字段无值时按源位置归属 owning heading。

带值 `for` 查询 heading projection label space。绑定目标可以来自标题节点的 `aat:addressLabel`、`aat:generatedAddressLabel` 或 `aat:headline`。绑定失败或多义绑定时，payload object 保留 `aat:forSelector` 和回源坐标，不连接到任何 heading node。`for` 字段不绑定到 payload object 自身的 role、普通字段谓词、raw 文本或 RDF IRI。

无值 `for` 不是 selector。投影器使用该 payload block 的源位置，找到覆盖该 block 起始行的最内层 heading node，并把 payload object 连接到该 heading node。无法确定 owning heading 时，不生成虚构 owner。

role token 表达 payload role，不决定节点 payload 身份。只有 role token、只有 source block language 或只有标题切片位置，都不足以使 listing block 成为节点 payload。

[source,asciidoc]
------
[.banana, for=delivery]
[source,json]
----
{
  "owner": {
    "team": "ops",
    "fallback": "manual-review"
  },
  "risk": {
    "level": "high",
    "signals": ["weather", "capacity"]
  }
}
----
------

投影为：

[source,turtle]
----
:heading-l5-o0 aat:payload [
  aat:payloadKind "node" ;
  aat:role "banana" ;
  aat:forSelector "delivery" ;
  aat:format "json" ;
  aat:relativePath "samples/structural-payload.adoc" ;
  aat:startLine 10 ;
  aat:endLine 23 ;
  aat:contentStartLine 13 ;
  aat:contentEndLine 22 ;
  aat:raw """{
  "owner": {
    "team": "ops",
    "fallback": "manual-review"
  },
  "risk": {
    "level": "high",
    "signals": ["weather", "capacity"]
  }
}"""
] .
----

无值 `for` 使用源位置归属 owning heading：

[source,asciidoc]
------
[.banana, for]
[source,json]
----
{"owner":{"team":"ops"}}
----
------

该 payload block 已经由 `for` 字段声明为节点 payload。投影器按源位置确定 owning heading，并通过 owning heading 的 `aat:payload` 连接 payload object。该表面不输出 `aat:forSelector`，因为无值 `for` 不是 selector literal。

=== 边 Payload

xref 的 `payload` 字段表达边 payload selector。带有匹配 ID 的 listing block 表达该边 payload。

边 payload 的绑定分两步。xref edge evidence 先用 `payload` 字段保存 `aat:payloadSelector`。投影器再用该 selector 匹配 listing block 的手动 ID。唯一匹配时，xref edge evidence 通过 `aat:payload` 连接该 payload 对象。未匹配或多义匹配时，边证据保留 `aat:payloadSelector`，不连接 payload 对象。

role token 不是边 payload 的识别条件。role token 可以作为源文档表面语义投影为 `aat:role`，但边 payload 绑定由 xref 的 `payload` selector 和 listing block 的 ID 决定。

[source,asciidoc]
------
xref:capacity[运力规则, rel=depends-on, payload=rel-delivery]

[#rel-delivery.pear]
[source,yaml]
----
reason:
  type: risk-control
  signals:
    - weather
    - capacity
  description: 配送策略需要读取运力规则来决定是否降级。
edge:
  direction: outbound
  required: true
----
------

投影为：

[source,turtle]
----
:xref-edge-l8-c8-o0 aat:payload [
  aat:payloadId "rel-delivery" ;
  aat:payloadKind "edge" ;
  aat:role "pear" ;
  aat:format "yaml" ;
  aat:relativePath "samples/structural-payload.adoc" ;
  aat:startLine 25 ;
  aat:endLine 37 ;
  aat:contentStartLine 28 ;
  aat:contentEndLine 36 ;
  aat:raw """reason:
  type: risk-control
  signals:
    - weather
    - capacity
  description: 配送策略需要读取运力规则来决定是否降级。
edge:
  direction: outbound
  required: true"""
] .
----

边 payload 归属于交叉引用边证据。它不归属于 source heading，也不归属于 target heading。

边 payload 的 selector 语境与普通 xref target selector 语境不同。xref 的 `payload` 字段只选择边 payload；普通 xref target 指向同一个 listing block ID 时，该 ID 按本地非标题 target 规则归属为所属标题的 `aat:addressLabel`。payload 对象仍然是复杂属性值，不作为 relation triple 的端点。

=== Opaque Raw

payload raw 不展开为 RDF 图。JSON、YAML、TOML、XML 或其它 payload 格式内部字段不进入标题投影图。

payload object 必须保存 payload kind、role、raw、relative path、完整 line span 和 content line span。payload format 来自 source block language。只有由 selector 显式指向的 payload block 才保存 `aat:payloadId`。

payload 对象是复杂属性值。它不是标题节点，不参与 `aat:containsDirectly`、`aat:childOrder` 或 `aat:documentOrder`，不作为 relation triple 的端点。公共查询应通过所属标题节点或 xref edge evidence 取得 payload，而不是把 payload 当作独立文档节点遍历。

payload listing 的本地 target ID 成为所属标题节点的 address label。该 address label 只用于寻址标题节点，不改变 payload 对象的复杂属性身份。

payload format 只来自 source block language。`data` 不选择 payload format，不选择 payload role，不决定 payload kind，不参与 payload binding。规范 payload 表面不使用 `data`。

== 输入契约

投影器消费 `AbundantDocument`。本章定义投影视角下的输入字段。实现者不得从本章未列入的外部来源补造结构事实。

=== Document 字段

`AbundantDocument.sourcePath` 表示输入源文件路径。投影器根据调用方提供的 document root 将该路径转换为 `relativePath`。

`AbundantDocument.title` 表示文档标题。文档标题投影为 document resource 的 `aat:TitleLabel`。该 label 使用 title node 的 line span。

`AbundantDocument.children` 表示文档顶层结构节点。投影器从该数组建立 document resource 到顶层结构 resource 的 `aat:containsDirectly`。

`AbundantDocument.targets` 表示当前文件内可引用 target 的 catalog。该 catalog 不默认生成独立 RDF resource。投影器将 target 条目用于补充 label catalog 和 official evidence。

`AbundantDocument.xrefOccurrences` 表示当前文件内的 xref occurrence。每个 xref occurrence 投影为 `aat:XrefOccurrence` resource。

`AbundantDocument.anchorOccurrences` 表示当前文件内的 anchor occurrence。anchor occurrence 可以投影为 `aat:AnchorTarget` 或 `aat:AnchorOccurrence` resource；当它可以被 xref target selector 引用时，它必须进入 label catalog。

=== SectionNode 字段

`SectionNode` 投影为 `aat:Section` resource。

字段解释：

[horizontal]
`level`:: section level，投影为 `aat:sectionLevel`。
`ids`:: section 的可寻址 label 值。
`title`:: section title label。
`line`:: 标题所在行。
`span`:: section 覆盖的 line span，投影为 `aat:startLine` 和 `aat:endLine`。
`titleSpan`:: 标题文本的 source span，用于 title label 的 line span。
`idOrigin`:: ID 来源，决定 `AddressLabel` 或 `GeneratedAddressLabel`。
`metadata`:: 紧邻标题的 metadata surface。
`children`:: section 内直接结构节点。

`idOrigin = "source"` 的 ID 投影为 `aat:AddressLabel`。`idOrigin = "asciidoctor-generated"` 的 ID 投影为 `aat:GeneratedAddressLabel`。两类 label 均不作为 resource identity。

=== ParagraphNode 字段

`ParagraphNode` 投影为 `aat:Paragraph` resource。

`text` 可以投影为 `aat:sourceText` 或 `aat:paragraphText`。`source.span` 投影为 paragraph 的 line span。`children` 中的 xref occurrence 和 anchor occurrence 可以通过 `aat:containsDirectly` 连接到 paragraph resource。

=== ListingNode 字段

`ListingNode` 投影为 `aat:ListingBlock` resource。

字段解释：

[horizontal]
`ids`:: listing 的 address label。
`title`:: listing 的 block title label。
`style`:: listing style，可投影为固定字段或 surface attribute。
`language`:: source listing 的 language，可投影为固定字段或 surface attribute。
`metadata`:: listing 前置 metadata surface。
`content`:: listing block 内容原文。
`metadataSpan`:: metadata 行范围。
`contentSpan`:: 内容行范围。
`span`:: listing 完整行范围。

listing 的完整 line span、metadata line span 和 content line span 必须分开投影。编程 agent 修改 block metadata 和 block content 时需要不同范围。

=== TableNode 字段

`TableNode` 投影为 `aat:TableBlock` resource。

`ids` 进入 address label。`title` 进入 block title label。`metadata` 进入 surface attribute 和 label。`span` 进入 line span。`rows` 和 `cells` 只有在输入对象提供稳定结构时才进入图；投影器不手写 raw table parser。

=== XrefOccurrenceNode 字段

`XrefOccurrenceNode` 投影为 `aat:XrefOccurrence` resource。

字段解释：

[horizontal]
`syntax`:: `shorthand` 或 `macro`。
`raw`:: 源文档中的 xref 原文。
`target`:: target selector。
`label`:: xref display label。
`attributes`:: xref named attributes。
`sourceSpan`:: xref occurrence 的 source span。
`containingSectionId`:: source node selector。
`scope`:: 当前恢复层对 local、external、unresolved 的表面分类。
`targetKind`:: 当前恢复层给出的词法提示。
`asciidoctor`:: official layer evidence。

`target` 必须作为 selector 保存。`containingSectionId` 必须作为 source node selector 参与 binding。`asciidoctor.resolvedId`、`asciidoctor.href` 和 `asciidoctor.reftext` 可以投影为 official evidence，但不得覆盖 raw target selector。

=== AnchorOccurrenceNode 字段

`AnchorOccurrenceNode` 投影为 anchor target 或 anchor occurrence resource。

`ids` 进入 `aat:AnchorLabel` 或 `aat:AddressLabel`。`reftext` 进入 `aat:ReftextLabel`。`sourceSpan` 进入 line span。`containingSectionId` 用于建立 anchor 与所在 section 之间的结构关系。

=== MetadataNode 字段

`MetadataNode` 表示源文档中的 metadata surface。投影器根据 `metadataKind`、`raw`、`line`、`ids`、`roles` 和 `attributes` 生成 label 或 surface attribute。

`metadataKind = "id"` 的 metadata 生成 address label。`metadataKind = "title"` 的 metadata 生成 block title label。`metadataKind = "attrlist"` 的 metadata 生成 role label 和 surface attribute。`metadataKind = "anchor"` 的 metadata 生成 anchor label。

=== TargetNode 字段

`TargetNode` 是 selector binding 的辅助 catalog 条目。它包含 `id`、`targetType`、`title`、`idOrigin`、`sourceSpan` 和 `asciidoctor` evidence。

投影器不得把每个 `TargetNode` 默认转成独立 target resource。target resource 应来自 section、listing、table、anchor 或 block 本身。`TargetNode` 的职责是把 target ID、title 和 official evidence 补充到 label catalog。

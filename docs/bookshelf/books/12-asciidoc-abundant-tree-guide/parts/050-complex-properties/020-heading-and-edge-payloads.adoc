[#heading-and-edge-payloads]
== 节点 Payload 与边 Payload

complex property 是值为 raw value object 的字段。它把 JSON、YAML 或其它 source block body 挂到 heading node 或 xref edge evidence 上。

Heading complex property 使用带 `for` 或 `forSelector` marker 的 source value block。property role 是字段名。

[source,asciidoc]
------
[#cold-chain-release.policy]
== 冷链出库放行策略

[.release-policy-config, for=cold-chain-release]
[source,json]
----
{"temperatureWindowCelsius":{"min":2,"max":8}}
----

[.review-playbook, for]
[source,yaml]
----
review_team: quality-ops
steps:
  - check last temperature checkpoint
----
------

带值 `for=cold-chain-release` 查询 heading label space。无值 `for` 使用 source ownership binding，按 source value block 起始行归属最内层 heading node。

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:...#heading-l1-o0>
  aat:release-policy-config <urn:aat:doc:...#payload-l4-o0> ;
  aat:review-playbook <urn:aat:doc:...#payload-l10-o0> .

<urn:aat:doc:...#payload-l4-o0> aat:forSelector "cold-chain-release" ;
  aat:format "json" .

<urn:aat:doc:...#payload-l10-o0> aat:format "yaml" .
----

xref edge complex property 由 xref named attribute 和 source value block 共同表达。attribute key 是字段名；attribute value 唯一匹配 source value block id 时，字段值是 raw value object。

[source,asciidoc]
------
冷链出库放行策略依赖 xref:temperature-audit[
  温控审计规则,
  rel=depends-on,
  dependency-evidence=rel-release-temperature-audit
]。

[#rel-release-temperature-audit]
[source,yaml]
----
source: quality-sop-2026
risk_level: high
reason: 放行策略必须读取温控审计结果。
----
------

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:...#xref-edge-l3-c12-o0> a aat:XrefEdge ;
  aat:dependency-evidence <urn:aat:doc:...#payload-l9-o0> .

<urn:aat:doc:...#payload-l9-o0> aat:sourceValueId "rel-release-temperature-audit" ;
  aat:format "yaml" ;
  aat:raw "source: quality-sop-2026\nrisk_level: high\nreason: 放行策略必须读取温控审计结果。" .
----

edge complex property 归属于 xref edge evidence。它不归属于 source heading，也不归属于 target heading。节点 payload 描述资源节点；边 payload 描述一次关系声明的证据、条件或配置。

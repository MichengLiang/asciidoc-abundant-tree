[#raw-value-object]
== Raw Value Object

raw value object 保存 source value block 的 raw、format、source coordinate 和 binding evidence。

[horizontal]
`aat:format`:: source block language。
`aat:raw`:: source block body 原文。
`aat:relativePath`、`aat:startLine`、`aat:endLine`:: source value block 的完整源文件行范围。
`aat:contentStartLine`、`aat:contentEndLine`:: source value block body 的源文件行范围。
`aat:forSelector`:: heading complex property 使用非空 selector binding 时保存的 heading selector。
`aat:sourceValueId`:: xref edge complex property 使用 source value id binding 时保存的 source value id。

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:cold-chain-release#payload-l10-o0>
  aat:format "json" ;
  aat:raw "{\"temperatureWindowCelsius\":{\"min\":2,\"max\":8}}" ;
  aat:relativePath "source/cold-chain-release.adoc" ;
  aat:startLine 10 ;
  aat:endLine 18 ;
  aat:contentStartLine 13 ;
  aat:contentEndLine 17 ;
  aat:forSelector "cold-chain-release" .
----

raw value object 不保存字段名。字段名由指向它的 field predicate 表达：

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:cold-chain-release#heading-l1-o0> aat:release-policy-config <urn:aat:doc:cold-chain-release#payload-l10-o0> .
----

raw value object 的 raw 是 opaque literal。JSON、YAML、TOML、XML 或其它格式内部字段由下游消费者解释。

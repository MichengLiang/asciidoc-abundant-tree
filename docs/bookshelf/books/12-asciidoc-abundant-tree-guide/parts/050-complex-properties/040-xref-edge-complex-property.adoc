[#xref-edge-complex-property]
== Xref Edge Complex Property

xref edge complex property 由 xref named attribute 和 source value block 共同表达。attribute key 是字段名；attribute value 唯一匹配 source value block id 时，字段值是 raw value object。

[source,asciidoc]
------
冷链出库放行策略依赖 xref:temperature-audit[
  温控审计规则,
  rel=depends-on,
  dependency-evidence=rel-release-temperature-audit
]。

[#rel-release-temperature-audit]
[source,yaml]
----
source: quality-sop-2026
risk_level: high
reason: 放行策略必须读取温控审计结果。
----
------

投影为：

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:...#xref-edge-l3-c12-o0> a aat:XrefEdge ;
  aat:dependency-evidence <urn:aat:doc:...#payload-l9-o0> .

<urn:aat:doc:...#payload-l9-o0> aat:sourceValueId "rel-release-temperature-audit" ;
  aat:format "yaml" ;
  aat:raw "source: quality-sop-2026\nrisk_level: high\nreason: 放行策略必须读取温控审计结果。" .
----

edge complex property 归属于 xref edge evidence。它不归属于 source heading，也不归属于 target heading。

== Format 与 Schema 消费

field predicate 与 format 是正交事实。field predicate 选择下游模型；format 选择 raw parser。

[source,typescript]
----
import { z } from "zod";
import YAML from "yaml";

const releasePolicyConfig = z.object({
  temperatureWindowCelsius: z.object({
    min: z.number(),
    max: z.number(),
  }),
  manualReviewWhen: z.array(z.string()),
});

function parseRaw(format: string, raw: string): unknown {
  if (format === "json") return JSON.parse(raw);
  if (format === "yaml" || format === "yml") return YAML.parse(raw);
  throw new Error(`unsupported raw format: ${format}`);
}

const data = parseRaw(format, raw);
const config = releasePolicyConfig.parse(data);
----

投影器保存 raw 事实。schema validation、默认值填充、字段解释和业务错误报告属于下游消费者。

[#description-list-fields]
== 描述列表字段

标题下第一个连续描述列表可以表达 heading fields。描述列表适合字段较多或字段值需要多行文本的标题。

[source,asciidoc]
----
[#capacity.rule, status=active]
== 运力规则

priority:: normal
summary::
运力规则集中说明配送容量、降级阈值和人工复核条件。
多行说明保留为同一个字段值。

正文从这里开始。
----

投影为：

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:guide#heading-l1-o0> aat:addressLabel "capacity" ;
  aat:priority "normal" ;
  aat:summary "运力规则集中说明配送容量、降级阈值和人工复核条件。\n多行说明保留为同一个字段值。" .
----

描述列表字段归属于紧邻的 heading node。字段段落结束后，后面的文本进入标题正文。

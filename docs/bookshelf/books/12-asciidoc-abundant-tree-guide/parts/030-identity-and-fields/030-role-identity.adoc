[#role-identity]
== Role 身份

role 写在标题 attrlist 的点号 token 位置。它表达 heading node 在当前书稿或领域模型中的身份。

[source,asciidoc]
----
[#delivery.policy, status=active]
== 配送策略

[#capacity.rule]
== 运力规则
----

投影为：

[source,turtle]
----
<urn:aat:doc:guide#heading-l1-c1> aat:addressLabel "delivery" ;
  aat:role "policy" .

<urn:aat:doc:guide#heading-l4-c1> aat:addressLabel "capacity" ;
  aat:role "rule" .
----

selector binding 使用 heading label space。role 是 heading field，提供筛选、报告和下游模型映射入口。下游模型可以把 role 映射为业务 class，也可以只把它作为普通字段消费。

role 词表属于书稿或领域模型。每个 role 在同一模型中保持单一含义。

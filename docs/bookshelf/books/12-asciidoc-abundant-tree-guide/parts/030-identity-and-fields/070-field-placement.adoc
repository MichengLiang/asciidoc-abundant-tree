[#field-placement]
== 字段落位

字段表面由字段主体、字段体积、读者可读性和下游消费动作共同决定。

[cols="1,2,2", options="header"]
|===
|字段表面 |源表面 |使用条件

|标题 attrlist
|`[#delivery.policy, status=active]`
|字段少，字段值短，字段需要在标题处立即可见。

|标题下描述列表
|`summary::` 后接字段值
|字段多，字段值长，字段需要多行文本。

|hmeta
|`hmeta:review-state[ready, label=可复核]`
|字段与正文句子共同表达。

|source value block
|`[.release-policy-config, for=delivery]`
|字段值是 JSON、YAML 或其它复杂 raw。

|xref named attributes
|`xref:capacity[rel=depends-on, weight=0.8]`
|字段主体是关系边证据。
|===

字段进入公共表面后，应被查询、校验、报告或下游模型消费。只服务临时作者记忆的内容保留为正文说明或注释语境。

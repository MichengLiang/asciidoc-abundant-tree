[#hmeta-inline-fields]
== Hmeta 句内字段

hmeta inline metadata 把短字段嵌入正文句子。读者看到显示文本，projection 保存结构值。

[source,asciidoc]
----
约束规则当前处于 hmeta:review-state[ready, label=可复核]。
----

投影为：

[source,turtle]
----
<urn:aat:doc:guide#heading-l1-c1> aat:role "rule" ;
  aat:review-state "ready" .
----

第一个 positional value 是结构值。`label` 是面向读者的显示文本。hmeta 适合把短状态、标记或分类留在句子中，同时提供稳定查询字段。

[#attrlist-fields]
== Attrlist 字段

标题前 attrlist 的 named attributes 投影为 heading literal fields。

[source,asciidoc]
----
[#delivery.policy, status=active, owner=ops]
== 配送策略
----

投影为：

[source,turtle]
----
<urn:aat:doc:guide#heading-l1-c1> aat:addressLabel "delivery" ;
  aat:status "active" ;
  aat:owner "ops" .
----

字段名映射为 `aat:` 命名空间下的 field predicate。字段值按源文档表面保存为 string literal。投影器不解释 `status`、`owner` 或其它业务字段的领域含义。

attrlist 适合少量短字段。字段较多或值需要换行时，使用标题下描述列表字段。

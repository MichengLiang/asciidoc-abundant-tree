== 模型质量报告

模型质量报告检查 role、rel、field、payload schema 和 hierarchy policy 的一致性。报告中的每个问题都指向源文件位置。

[source,json]
----
{
  "kind": "missing-required-field",
  "role": "shipment",
  "field": "destination",
  "headline": "批次运输任务CT-2026-0618",
  "relativePath": "source/cold-chain.adoc",
  "line": 11
}
----

质量报告把领域模型规则连接回作者可修改的源表面。它不是投影器错误报告；它属于当前业务模型。

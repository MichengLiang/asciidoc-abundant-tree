== 模型质量报告

模型质量报告检查 role、rel、field、payload schema 和 hierarchy policy 的一致性。报告中的每个问题都指向源文件位置。

[source,json]
----
{
  "kind": "missing-required-field",
  "role": "shipment",
  "field": "destination",
  "headline": "批次运输任务CT-2026-0618",
  "relativePath": "source/cold-chain.adoc",
  "line": 11
}
----

质量报告把领域模型规则连接回作者可修改的源表面。它不是投影器错误报告；它属于当前业务模型。

模型质量报告覆盖以下对象：

[horizontal]
role coverage:: heading node 的 role 是否属于 role 词表。
required fields:: role 要求的字段是否存在。
relation endpoint:: rel 词表要求的 source role 与 target role 是否匹配。
edge fields:: rel 词表要求的 xref named attributes 是否存在。
payload schema:: raw value object 是否满足对应 field predicate 的 schema。
hierarchy policy:: 标题层级生成的业务边是否符合当前领域约定。

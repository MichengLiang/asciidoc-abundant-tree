[#rel-vocabulary]
== Rel 词表设计

rel 词表定义业务关系谓词。xref 的 `rel` 字段选择关系谓词；TS/JS consumer 解释该谓词在领域图中的含义。

[source,javascript]
----
export const relations = {
  "is-a": "分类关系",
  "part-of": "组成关系",
  "has-part": "包含部件",
  "governed-by": "受规则约束",
  monitors: "监控",
  triggers: "触发",
};
----

关系谓词描述边。节点身份使用 role。边属性使用 xref named attributes。

rel 词表项包含 relation token、方向、端点约束和边字段约束。端点约束检查 source role 与 target role，边字段约束检查 xref edge evidence。

[source,typescript]
----
export const relationVocabulary = {
  monitors: {
    sourceRole: "sensor",
    targetRole: "payload",
    requiredEdgeFields: ["confidence"],
  },
  triggers: {
    sourceRole: "policy",
    targetRole: "process",
    requiredEdgeFields: ["condition"],
  },
};
----

[#domain-object-to-heading-node]
== 从领域对象到标题节点

领域对象进入书稿时，先判断它是否需要被引用、查询、校验、回源或单独维护。满足这些动作的对象适合作为 heading node。

[source,asciidoc]
----
[.recipe]
== 番茄炒蛋

[.ingredient]
=== 鸡蛋

[.ingredient]
=== 番茄
----

标题节点代表菜谱、食材、规则、运输任务、传感器、图片资产、PDF 证据片段、K8S Service、剧本场景或游戏任务。领域对象的本质复杂度由领域承担；书稿表面降低录入、查询、回源和 agent 协作的偶然复杂度。

对象粒度由消费动作决定。需要独立查询、独立引用、独立校验或独立回源的对象进入标题；只描述某个标题属性的事实进入 field、payload 或正文。

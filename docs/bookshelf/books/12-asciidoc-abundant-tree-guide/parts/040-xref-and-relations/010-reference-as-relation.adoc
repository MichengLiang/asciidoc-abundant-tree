[#evidence-note.evidence]
== 证据说明
----

没有 `rel` 的 xref 投影为 `aat:references`。带 `rel` 的 xref 选择 relation predicate。普通 token 进入 `rel:` 命名空间；绝对 IRI 使用该 IRI；已知 CURIE 使用展开后的 IRI。

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .
@prefix rel: <https://micheng.dev/ns/asciidoc-relation#> .

<urn:aat:doc:...#heading-l1-o0> rel:depends-on <urn:aat:doc:...#heading-l7-o0> ;
  aat:references <urn:aat:doc:...#heading-l10-o0> .
----

`aat:references` 表达普通参见关系。明确业务关系使用 `rel` 字段。`rel` 的业务语义由当前书稿或领域模型的受控词表定义，投影器保存源表面并生成关系谓词。

[horizontal]
depends-on:: 当前标题的判断、规则或操作以目标标题为依据。
illustrates:: 当前标题提供目标标题的示例。
defines:: 当前标题给出目标标题所代表对象的定义。
constrains:: 当前标题对目标标题的合法写法或范围施加约束。
is-a:: 当前标题所代表对象属于目标标题所代表类别。
part-of:: 当前标题所代表对象是目标标题所代表整体的组成部分。

relation triple 的端点保持为 heading node。xref target selector 指向 listing、table、block、inline anchor 或 source value block 的本地 target ID 时，target heading 是该 target ID 所属的 heading node；被引用的具体 AsciiDoc target 表面由 edge evidence 的 `aat:targetSelector` 和 official resolved facts 表达。

[#xref-relation-edge]
== Xref 创建关系边

xref 位于某个 heading slice 中。该 heading node 是关系 source。xref target selector 绑定到 heading label space 后，命中的 heading node 是关系 target。

[source,asciidoc]
----
[#delivery.policy]
== 配送策略

配送策略依赖 xref:capacity[运力规则, rel=depends-on]。

[#capacity.rule]
== 运力规则
----

投影为：

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .
@prefix rel: <https://micheng.dev/ns/asciidoc-relation#> .

<urn:aat:doc:...#heading-l1-o0> rel:depends-on <urn:aat:doc:...#heading-l6-o0> .

<urn:aat:doc:...#xref-edge-l4-c7-o0> a aat:XrefEdge ;
  aat:sourceHeading <urn:aat:doc:...#heading-l1-o0> ;
  aat:targetHeading <urn:aat:doc:...#heading-l6-o0> ;
  aat:targetSelector "capacity" .
----

relation triple 服务图查询。xref edge evidence 服务回源、审计、边字段和 official binding 查询。

xref target selector 指向 listing、table、block、inline anchor 或 source value block 的本地 target ID 时，target heading 是该 target ID 所属的 heading node。relation triple 的端点保持为 heading node；被引用的具体 AsciiDoc target 表面由 edge evidence 的 `aat:targetSelector` 和 official resolved facts 表达。

[#relation-predicate]
== 关系谓词

`rel` 是 xref 的 relation control field。它选择主 relation triple 的 predicate。

[source,asciidoc]
----
xref:capacity[运力规则, rel=depends-on]
----

普通 token 进入 `rel:` 命名空间：

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .
@prefix rel: <https://micheng.dev/ns/asciidoc-relation#> .

<urn:aat:doc:guide#heading-l1-o0> aat:addressLabel "delivery" ;
  rel:depends-on <urn:aat:doc:guide#heading-l4-o0> .

<urn:aat:doc:guide#heading-l4-o0> aat:addressLabel "capacity" .
----

`rel` 值是普通 token 时，predicate 使用 `rel:` 命名空间下的稳定 IRI-safe 映射。`rel` 值是绝对 IRI 时，predicate 使用该 IRI。`rel` 值是已知 CURIE 时，predicate 使用展开后的 IRI。`rel` 不能映射为合法 IRI 时，edge evidence 保留 `aat:rel`，主 relation triple 不生成。

`rel` 的业务语义由当前书稿或领域模型的受控词表定义。投影器只保存源表面并生成关系谓词。

[horizontal]
depends-on:: 当前标题的判断、规则或操作以目标标题为依据。
illustrates:: 当前标题提供目标标题的示例。
defines:: 当前标题给出目标标题所代表对象的定义。
constrains:: 当前标题对目标标题的合法写法或范围施加约束。
is-a:: 当前标题所代表对象属于目标标题所代表类别。
part-of:: 当前标题所代表对象是目标标题所代表整体的组成部分。

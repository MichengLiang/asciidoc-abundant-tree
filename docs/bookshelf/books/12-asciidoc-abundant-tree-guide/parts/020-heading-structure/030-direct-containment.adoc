[#direct-containment]
== 直接包含

`aat:containsDirectly` 表达父标题到直接子标题的结构边。该关系来自 logical heading tree。

[source,asciidoc]
----
= 知识库

== 配送策略

=== 运力约束

== 计费策略
----

投影图输出直接父子关系：

[source,turtle]
----
<urn:aat:doc:guide#heading-l1-c1> aat:containsDirectly <urn:aat:doc:guide#heading-l3-c1> .
<urn:aat:doc:guide#heading-l1-c1> aat:containsDirectly <urn:aat:doc:guide#heading-l7-c1> .
<urn:aat:doc:guide#heading-l3-c1> aat:containsDirectly <urn:aat:doc:guide#heading-l5-c1> .
----

直接包含不表达传递闭包。`知识库` 直接包含 `配送策略` 和 `计费策略`；`知识库` 不直接包含 `运力约束`。

读取 direct children：

[source,sparql]
----
SELECT ?child ?headline ?childOrder WHERE {
  ?parent aat:headline "知识库" .
  ?parent aat:containsDirectly ?child .
  ?child aat:headline ?headline ;
         aat:childOrder ?childOrder .
}
ORDER BY ?childOrder
----

结构边只连接 heading node。代码块、表格、inline anchor 和 raw value object 通过其它事实归属于 heading node。

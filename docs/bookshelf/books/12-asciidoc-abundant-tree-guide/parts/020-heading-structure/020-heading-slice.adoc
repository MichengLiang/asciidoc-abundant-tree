[#heading-slice]
== 标题切片

heading slice 是标题节点对应的连续源文本区域。切片起点是标题头部 metadata 的第一行；没有 metadata 时，起点是标题行。切片终点是下一个标题切片起点的前一行；没有下一个标题时，终点是源文件末尾。

[source,asciidoc]
----
[#capacity.rule, status=active]
== 运力规则

priority:: normal

运力规则描述配送容量判断。
----

该标题切片从 `[#capacity.rule, status=active]` 开始，到下一个标题切片之前结束。

[source,turtle]
----
@prefix aat: <https://micheng.dev/ns/asciidoc-abundant-tree#> .

<urn:aat:doc:guide#heading-l1-o0> a aat:Heading ;
  aat:addressLabel "capacity" ;
  aat:headline "运力规则" ;
  aat:raw """[#capacity.rule, status=active]
== 运力规则

priority:: normal

运力规则描述配送容量判断。
""" ;
  aat:metadataStartLine 1 ;
  aat:metadataEndLine 1 ;
  aat:headingLine 2 ;
  aat:contentStartLine 4 ;
  aat:contentEndLine 6 .
----

行号使用 1-based line number。line span 是闭区间。`aat:raw` 是回源编辑和审计的基础事实。

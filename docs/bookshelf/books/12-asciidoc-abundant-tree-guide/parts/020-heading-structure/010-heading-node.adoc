[#heading-node]
== 标题节点

heading node 由 AsciiDoc 等号标题创建。源表面中的 `=`、`==`、`===` 直到 `======` 均创建标题节点。

[source,asciidoc]
----
= 项目知识库

== 配送策略

=== 运力约束
----

投影图为每个标题输出 `aat:Heading`、`aat:headline`、`aat:headingLevel`、`aat:documentOrder` 和回源坐标。

[source,turtle]
----
<urn:aat:doc:...#heading-l1-o0> a aat:Heading ;
  aat:headline "项目知识库" ;
  aat:headingLevel 0 ;
  aat:documentOrder 1 .

<urn:aat:doc:...#heading-l3-o0> a aat:Heading ;
  aat:headline "配送策略" ;
  aat:headingLevel 1 ;
  aat:documentOrder 2 .

<urn:aat:doc:...#heading-l5-o0> a aat:Heading ;
  aat:headline "运力约束" ;
  aat:headingLevel 2 ;
  aat:documentOrder 3 .
----

heading node 的 IRI 由投影器生成。作者写下的 ID、生成 label 和标题文本进入 label space，不构成节点 IRI。查询者先按 label 查 heading node，再读取该节点的字段、关系和回源坐标。

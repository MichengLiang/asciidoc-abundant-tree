== Book Workspace

Book Workspace 展示多文件书稿的 source-aware projection。领域对象是一本文档书；它由 entry file、frontmatter、parts、backmatter 和术语表共同组成。

[horizontal]
source:: `cases/050-book-workspace/source/book.adoc`、`source/frontmatter/`、`source/parts/`、`source/backmatter/`
projection:: `projection/book.ttl`、`projection/book.jsonld`
model:: `model/xref-audit.ts`、`model/source-set-report.ts`
reports:: `reports/source-set.json`、`reports/xref-audit.json`、`reports/index-terms.json`
views:: `views/book-outline.mmd`

entry file 通过 include graph 构造 logical document：

[source,asciidoc]
----
= Book Workspace Demo
:doctype: book

\include::frontmatter/preface.adoc[]

\include::parts/010-object/010-object-boundary.adoc[]

\include::backmatter/glossary.adoc[]
----

book-entry mode 让消费者在整本书层面查询 heading tree，同时保留每个 heading 的 origin source file 和 origin line。`source-set-report.ts` 读取 source file reconstruction surface，输出参与书稿构造的源文件集合。`xref-audit.ts` 检查 unresolved、ambiguous 和 unused stable ID，报告记录 relativePath 和 line。

该案例展示 frontmatter、parts、chapters、backmatter、glossary、bibliography 和 index 的工程意义：书籍不是散落页面，而是长期可维护、可引用、可索引、可回源的知识人工制品。

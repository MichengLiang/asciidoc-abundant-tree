== PDF / Word / RAG Provenance Index

PDF / Word / RAG Provenance Index 把外部文档中的证据片段放入可查询图索引。领域对象是 claim、chunk、段落、页面区域和证据片段。书稿标题节点为外部文件中的证据建立名称、关系、locator payload 和回源入口。

claim 和 evidence chunk 都是 heading node。xref `rel=supported-by` 表达主张和证据关系。`source-locator` payload 保存 PDF page/bbox、TextQuoteSelector、TextPositionSelector、Word paraId/bookmark、char offset 或网页 selector。

=== Locator Schema

`locator-schema.ts` 定义 locator payload 的可用形状。PDF locator 使用 page 和 bbox。Word locator 使用 paraId、bookmark 或内容控件 ID。Web/RAG locator 使用 text quote、text position 或 source URL。schema 不替外部文件建模；它保存打开原文所需的定位事实。

=== 输出表面

`rag-index.ts` 读取 projection，生成 `rag-citations.json` 和 `source-locators.json`。`pdf-highlight-data.json` 把图中的 locator 转成前端高亮数据。`evidence-graph.mmd` 表达 claim、chunk 和 source document 的证据关系。

=== 回源意义

查询先发生在文本图上。命中证据后，adapter 根据 locator 打开 PDF、Word 或网页原文位置。书稿保存可维护索引；外部文件保存原始材料；locator payload 把两者连接成可审计证据链。

== Multimodal Asset Catalog

Multimodal Asset Catalog 把图片和多模态资产放入标题资源节点。领域对象是资产集合、单张图片、项目、人物、地点和视觉特征。图片文件留在文件系统中；书稿标题节点保存语义、字段、视觉 payload 和项目关系。

`path` 和 `license` 是短字段。`location` 和 `tags` 是描述列表字段。`vision-profile` 是视觉模型输出 payload。xref `rel=used-in` 把图片资产连到项目。

=== 资产模型

`asset-schema.ts` 约束视觉 payload：构图、主色、对象、文字区域、风格说明、人物、地点和重复候选。`asset-report.ts` 读取 heading nodes、fields、payload raw 和 xref relations，生成 asset index、duplicate candidates 和 project usage report。

=== 输出表面

`asset-index.json` 是资产查询入口。`duplicate-candidates.json` 保存由 hash、视觉特征或人工字段得到的重复候选。`project-usage.json` 输出项目到资产的使用关系。`asset-graph.mmd` 把项目、资产、地点和关系放入可读图。

=== 回源意义

文件资产在这里进入标题资源节点。code agent 可以搜索纯文本目录、读取图片、把观察写回 payload、运行报告脚本，再用 source coordinate 回到资产标题继续补字段。资源文件保持原路径；资源语义进入书稿资源图。

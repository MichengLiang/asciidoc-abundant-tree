== Cold Chain Operations Graph

Cold Chain Operations Graph 面向冷链运输规则、运输任务、载荷、传感器和处置流程。模型重点是规则约束、部件组成、监控关系、触发关系和边属性。

=== 源书稿

[source,asciidoc]
----
[#temperature-rule.policy, status=active]
== 2-8C温控规则

[#shipment-ct-2026-0618.shipment, status=in-transit]
=== 批次运输任务CT-2026-0618

运输任务包含 xref:vaccine-box[疫苗箱, rel=has-part]。
温度记录仪 xref:temperature-deviation[温度偏离处置流程, rel=triggers, condition=超温超过15分钟]。
----

短字段保存任务状态。xref `rel=has-part` 表达部件组成。xref `rel=triggers` 表达异常触发关系，`condition` 是边字段。标题层级把运输任务置于温控规则之下。

=== 建模政策

`policy.ts` 把 child-to-parent 层级解释为 `governed-by`。运输任务在结构上属于温控规则的子标题，在业务图中成为“受温控规则约束”的任务。显式 xref 生成 `has-part`、`monitors` 和 `triggers` 等业务边。

边字段只属于 xref occurrence。`condition=超温超过15分钟` 描述触发边，不描述 source heading，也不描述 target heading。

=== 输出表面

`business-graph.ts` 生成三类视图：`rules.mmd` 表达规则对流程的触发；`composition.mmd` 表达运输任务、疫苗箱和温度记录仪的组成；`overview.mmd` 合并规则、组成、监控和触发关系。报告保留每条业务边的 origin、raw 和 source line。

=== 回源意义

冷链语义来自 role 词表、rel 词表、字段约束和 hierarchy policy。投影图提供统一结构事实；业务图把这些事实解释成冷链操作关系。

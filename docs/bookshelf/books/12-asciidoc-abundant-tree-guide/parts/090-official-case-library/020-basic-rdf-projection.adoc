== Basic RDF Projection

Basic RDF Projection 是结构基线。标题、字段、xref、local target alias 和 hmeta 共同建立一份投影夹具，使后续业务目录共享同一组底层事实：heading node、field predicate、relation triple、xref edge evidence、source coordinate 和 heading tree order。

=== 投影事实

`headings.json` 按 `aat:documentOrder` 输出标题树。`xref-evidence.json` 输出 xref occurrence 的 raw、selector、relation、source line 和 target heading。`heading-tree.mmd` 把同一组 heading order 事实转换成 Mermaid outline。

`structure-shapes.ttl` 检查 heading 是否暴露 headline、source coordinate 和结构字段。SHACL 报告不是业务质量判断；它确认投影层给后续消费者提供了可依赖的公共字段。

=== 消费动作

`model/query.mjs` 读取 projection 后执行两个动作：按 `aat:documentOrder` 打印标题树，按 `aat:XrefEdge` 读取边证据。第一个动作证明章节结构可查询；第二个动作证明关系不是只有 triple，还保留源文档中的出现位置和 raw 表面。

=== 回源意义

后续业务目录中的 role、rel、payload、report 和 view 都回到这里确立的公共事实：标题节点、字段谓词、关系边、边证据和 source coordinate。

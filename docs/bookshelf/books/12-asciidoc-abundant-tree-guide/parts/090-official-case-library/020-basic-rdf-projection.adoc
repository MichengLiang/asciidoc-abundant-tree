== Basic RDF Projection

Basic RDF Projection 展示投影层核心结构。领域对象是一个小型结构夹具；它只使用标题、字段、xref、local target alias 和 hmeta，避免业务语义抢走投影契约的位置。

该案例覆盖 document title heading、manual address label、generated address label、heading direct fields、role、heading tree、explicit relation、default relation、xref evidence、local target alias、SHACL validation 和 Oxigraph 查询。

`model/query.mjs` 读取 projection，生成两个报告：`headings.json` 按 `aat:documentOrder` 输出 heading tree；`xref-evidence.json` 输出 xref occurrence 的 raw、selector、relation、source line 和 target heading。`structure-shapes.ttl` 检查 heading 是否暴露 headline、source coordinate 和必需字段。

读者动作是：查看源书稿，生成 projection，按 `aat:documentOrder` 打印标题树，按 `aat:XrefEdge` 读取边证据，按 SHACL shape 检查结构约束。这个案例给后续所有业务案例提供投影层基线。

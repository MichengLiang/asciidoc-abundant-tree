== 冷链出库放行策略

冷链出库放行策略依赖 xref:temperature-audit[

  rel=depends-on,

  dependency-evidence=rel-release-temperature-audit
]。

[.release-policy-config, for=cold-chain-release]
[source,json]
----
{
  "temperatureWindowCelsius": { "min": 2, "max": 8 },
  "manualReviewWhen": ["sensor_gap", "route_exception"]
}
----
------

`release-policy-config` 是 heading complex property。`dependency-evidence` 是 edge complex property。两者都投影为 raw value object；区别在于一个描述策略节点，一个描述依赖关系的证据。

=== Schema 消费

`payload-schema.ts` 定义策略配置、复核手册和依赖证据的结构。`consume-payloads.ts` 按 field predicate 选择 schema，按 `aat:format` 选择 parser，按 source coordinate 把解析结果带回源文档。

字段名和 format 是正交事实。`aat:release-policy-config` 选择业务模型；`aat:format "json"` 选择 parser；`aat:raw` 保存 source block body；`aat:contentStartLine` 和 `aat:contentEndLine` 指向可编辑 payload body。

=== 输出表面

`payload-summary.json` 汇总策略温度窗口、人工复核条件、复核手册步骤和依赖证据风险级别。`source-lines.md` 把每个 payload field、format、summary 和 line span 写成可审查报告。`release-policy.mmd` 把策略、审计规则和 payload 关系画成放行闭环。

=== 回源意义

复杂信息的落位决定回源动作。策略配置属于 heading，依赖证据属于 edge evidence。source-aware report 保存 payload field、format、source line 和解析结果，使作者回到对应 source value block 修改配置、手册或证据。

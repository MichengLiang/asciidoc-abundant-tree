== 交叉引用维护

跨文件书稿仍使用 heading label space 进行 xref binding。book-entry mode 改变输入构造方式，不改变 selector binding 的公共契约。source coordinate 指向 origin source file。

=== 源表面

[source,asciidoc]
----
查询契约见 xref:sparql-query-surface[SPARQL 查询入口]。
----

xref selector 查询 logical document 的 heading label space。命中 heading node 后，edge evidence 保存 xref occurrence 的 origin relativePath、line、column、raw 和 target selector。

=== 审计报告

xref audit 读取 unresolved、ambiguous 和 unused stable ID。报告记录 source file 与 line：

[source,json]
----
{
  "kind": "unresolved-xref",
  "selector": "missing-target",
  "relativePath": "parts/040-xref-and-relations/060-selector-binding.adoc",
  "line": 18
}
----

=== 维护动作

维护动作从报告返回源文件。projection 不替作者修复源文档。未绑定 selector 通常需要补 stable ID、改 target selector 或调整标题文本。多义 selector 需要收窄 label space。unused stable ID 需要判断它是否仍承担长期引用入口。

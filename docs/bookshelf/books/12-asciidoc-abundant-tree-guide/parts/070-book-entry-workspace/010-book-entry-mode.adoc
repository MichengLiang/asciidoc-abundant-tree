[#book-entry-mode]
== Book-entry Mode

book-entry mode 接受一个 entry file，读取受支持 include directive 指向的 source files，构造一份带 line origin 的 logical document。

[source,typescript]
----
import { parseAbundantTree, rdf12 } from "asciidoc-abundant-tree";

const document = parseAbundantTree({
  sourcePath: "book/book.adoc",
  mode: "book-entry",
  documentRoot: "book",
});

const projection = rdf12(document, { documentRoot: "book" });
----

CLI：

[source,bash]
----
asciidoc-abundant-tree book/book.adoc \
  --mode book-entry \
  --document-root book \
  --format rdf12 > projection/book.ttl
----

book-entry mode 的输入模式由调用者显式声明。`:doctype: book` 是源文档事实，不是模式开关。

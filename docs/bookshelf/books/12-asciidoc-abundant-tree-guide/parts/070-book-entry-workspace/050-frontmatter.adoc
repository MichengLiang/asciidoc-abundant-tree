[#frontmatter]
== Frontmatter

frontmatter 保存读者进入书籍对象所需的出版信息、摘要、前言、致谢、引言和阅读路径。它位于 `book.adoc` 中正文 parts 之前。半书名页、标题页和版权页提供书籍身份；摘要和引言提供对象入口；阅读路径连接不同消费者动作与正文部件。

[source,asciidoc]
----
\include::frontmatter/half-title.adoc[]

\include::frontmatter/title-page.adoc[]

\include::frontmatter/copyright.adoc[]

[abstract]
\include::frontmatter/abstract.adoc[]

[colophon]
\include::frontmatter/colophon.adoc[]

[preface]
\include::frontmatter/preface.adoc[]

\include::frontmatter/introduction.adoc[]
----

frontmatter 文件参与 source set。其标题、字段和引用同样可以被 projection 和查询消费。

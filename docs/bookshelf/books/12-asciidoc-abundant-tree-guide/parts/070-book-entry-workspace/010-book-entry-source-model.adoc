[#book-entry-source-model]
== Book-entry Source Model

book-entry mode 把一个 entry file 和它到达的 included source files 构造成一份带 origin mapping 的 logical document。parser 读取 logical document；报告、查询和回源动作使用 origin source coordinate。

=== Entry File

entry file 是 book-entry mode 的显式输入。`:doctype: book` 是源文档事实，mode 仍由调用者声明。

[source,typescript]
----
import { parseAbundantTree, rdf12 } from "asciidoc-abundant-tree";

const document = await parseAbundantTree({
  sourcePath: "book/book.adoc",
  mode: "book-entry",
  documentRoot: "book",
});

const projection = rdf12(document, { documentRoot: "book" });
----

CLI 表面使用同一组输入事实：

[source,bash]
----
asciidoc-abundant-tree book/book.adoc \
  --mode book-entry \
  --document-root book \
  --format rdf12 > projection/book.ttl
----

=== Source Set

source set 是 entry file 通过受支持 include directive 到达的 source files 集合。

[source,asciidoc]
----
= Book Entry Demo
:doctype: book

\include::chapters/01-overview.adoc[]

\include::chapters/02-operations.adoc[]
----

`documentRoot` 是 relativePath 基准和路径边界。RDF12 输出为 source set 提供 source file reconstruction surface：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?path WHERE {
  ?sourceDoc a aat:AsciiDocSourceDocument ;
             aat:sourceFile ?sourceFile .
  ?sourceFile a aat:SourceFile ;
              aat:relativePath ?path .
}
ORDER BY ?path
----

source set 包含 entry file 和 included files。只贡献 attributes 或其它非结构节点的 source file 仍属于 source set。同一绝对路径在 source set 中只有一个 file record；重复 include 在 logical document 中出现多次，source file reconstruction surface 仍按 source file identity 保存一份原始文本。

=== Logical Document

logical document 是 book-entry mode 构造出的 in-memory AsciiDoc 文本。include directive line 在 logical text 中被 included file lines 替换。

Entry file：

[source,asciidoc]
----
= 第一部：投影对象

\include::chapters/01-projection-object.adoc[]
----

Chapter file：

[source,asciidoc]
----
[#projection-object]
== 投影对象

投影对象保存输入事实、图事实和回源坐标。
----

Logical text：

[source,asciidoc]
----
= 第一部：投影对象

[#projection-object]
== 投影对象

投影对象保存输入事实、图事实和回源坐标。
----

logical text 服务结构解析。作者编辑对象仍然是 entry file 和 included source files。directive line 保留在 entry file 的原始 source text 中，并通过 source file reconstruction surface 回源。

=== Line Origin

line origin 把 logical line 映射到原始 source file 和 source line。它是 book-entry 回源能力的构成性对象。

[source,typescript]
----
export type LineOrigin = {
  logicalLine: number;
  absolutePath: string;
  relativePath: string;
  sourceLine: number;
};
----

[source,text]
----
logical line 27, column 14
  -> origin relativePath "chapters/02-operations.adoc"
  -> origin line 8, column 14
----

logical document 是解析表面。line origin 是回源表面。二者同时成立，多文件书稿才能生成整体结构，同时把每个 heading、xref、raw value object 指回原始章节文件。

[#logical-document]
== Logical Document

logical document 是 book-entry mode 构造出的 in-memory AsciiDoc 文本。parser 把它作为一份逻辑 source document 解析。

Entry file：

[source,asciidoc]
----
= 第一部：投影对象

\include::chapters/01-projection-object.adoc[]
----

Chapter file：

[source,asciidoc]
----
[#projection-object]
== 投影对象

本章定义投影对象的输入事实。
----

Logical text：

[source,asciidoc]
----
= 第一部：投影对象

[#projection-object]
== 投影对象

本章定义投影对象的输入事实。
----

logical text 服务结构解析。作者编辑对象仍然是 entry file 和 included source files。

include directive line 在 logical text 中被 included file lines 替换。directive line 保留在 entry file 的原始 source text 中，并通过 source file reconstruction surface 回源。logical text 是解析表面，不写入 `build/adoc`，也不成为作者编辑对象。

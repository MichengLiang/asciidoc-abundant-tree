== 摘要

本书定义一种书稿到知识图谱的工作方式。作者用 AsciiDoc 标题、字段、交叉引用和 source value block 组织可读书稿；`asciidoc-abundant-tree` 将这些源表面投影为 RDF 1.2 图；TS/JS 消费程序在图上执行查询、校验、业务建模、视图生成和回源报告。

本书的核心单位是 heading node。标题节点承担阅读单位、查询单位、回源单位和领域资源容器。xref 创建标题节点之间的非层级边；field 和 raw value object 保存节点或边证据上的结构化信息；source coordinate 把查询结果连接回源文件行号。

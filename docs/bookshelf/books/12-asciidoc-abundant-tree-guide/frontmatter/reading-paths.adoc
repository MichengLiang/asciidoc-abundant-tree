== 阅读路径

AsciiDoc 作者从第一部读到第五部，先掌握标题节点、字段、引用和复杂属性的源表面，再进入第七部理解多文件书稿组织。

TypeScript / JavaScript 开发者从第一部建立投影闭环，接着阅读第六部的 RDF/JS、SPARQL、SHACL 和报告章节，再进入第九部复制官方案例。

领域建模者从第八部开始建立 role、rel、field、payload schema 和 hierarchy policy，再回到第二部到第五部核对每种建模表面的投影规则。

书籍维护者阅读第七部和后置附录，使用 book-entry、frontmatter、parts、chapters、backmatter、术语表、参考文献和索引维护长期书稿。

AI agent 操作者重点阅读第一部、第六部和第九部。source coordinate、source-aware report 和案例目录把查询结果连接到可编辑源文件。

RDF 与知识图谱工程师阅读第二部到第六部，核对 heading node、xref edge evidence、raw value object、RDF 1.2 reifier、SHACL 和 SPARQL 查询面。

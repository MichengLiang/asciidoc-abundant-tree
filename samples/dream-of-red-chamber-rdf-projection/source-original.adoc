== 贾府概况

贾府分宁、荣二公之后，以荣国府为主线。
府中四代人，从贾母的慈威并施，到宝玉的叛逆出走，
写尽了一个钟鸣鼎食之家由盛转衰的全过程。

宁国府一支以贾珍为首，荒淫无度，先一步败落。
荣国府则在贾母的庇护下多撑了几年，
最终也难逃抄家之运。

// 荣国府 · 第二代

[#jiamu.section, faction=荣国府, gender=女, generation=第二代]
== 贾母

贾府的定海神针，人称"老祖宗"。
史侯之女，嫁入贾家后主持荣国府数十年。
年事虽高，心思通透，府中大小事务逃不过她的眼。

她最疼爱 xref:贾宝玉[贾宝玉, rel=grandmother-of, weight=0.9]，
为此不惜与 xref:贾政[贾政, rel=mother-of, weight=0.5] 的严厉管教对着干。
xref:林黛玉[林黛玉, rel=grandmother-of, weight=0.85] 是她嫡亲外孙女，
自幼接来身边教养，疼爱有加。

贾母善于享乐，听戏、赏花、摆宴样样精通。
她主持的元宵夜宴、中秋赏月，是全书最热闹的场景。
但这份热闹底下，藏着她对家族前途的隐忧。

// 荣国府 · 第三代

[#jiazheng.section, faction=荣国府, gender=男, generation=第三代]
== 贾政

荣国府二老爷，工部员外郎。
为人方正古板，一心望子成龙。
对 xref:贾宝玉[贾宝玉, rel=father-of, weight=0.3] 管教极严，
动辄训斥，曾将宝玉打得皮开肉绽（"不肖种种大承笞挞"一回）。

贾政其实文才平平，却偏爱附庸风雅，
养了一群清客相公谈诗论文。
他内心对宝玉的聪慧并非不知，只是恨铁不成钢。

与 xref:王夫人[王夫人, rel=married-to, weight=0.5] 夫妻多年，
感情平淡，相敬如宾。
xref:贾母[贾母, rel=son-of, weight=0.5] 是他的母亲，
他在母亲面前始终恭顺，不敢违拗。

[#wangfuren.section, faction=荣国府, gender=女, generation=第三代]
== 王夫人

贾政之妻，宝玉之母。
出身金陵王家，与 xref:王熙凤[王熙凤, rel=aunt-of, weight=0.6] 是姑侄。
为人木讷老实，不善言辞，但心地并不慈善。
她抄检大观园、撵走晴雯，手段狠辣。

王夫人吃斋念佛，看似与世无争，
实则对 xref:林黛玉[林黛玉, rel=dislikes, weight=0.7] 颇有成见，
认为她体弱多病、性情乖张，不宜做宝玉的妻子。
她更属意 xref:薛宝钗[薛宝钗, rel=Prefers-as-daughter-in-law, weight=0.8]，
因为宝钗性格稳重，符合她心中贤妻的标准。

[#jiashu.section, faction=荣国府, gender=男, generation=第三代]
== 贾赦

荣国府大老爷，贾母长子。
袭了一等将军的爵位，却不务正业，
整日与小妾喝酒取乐。
他曾想纳 xref:鸳鸯[鸳鸯, rel=desires, weight=0.4] 为妾，
被贾母痛斥一顿。

贾赦与 xref:贾政[贾政, rel=brother-of, weight=0.3] 兄弟不和，
表面上维持着体面，暗地里各怀心思。
他与 xref:邢夫人[邢夫人, rel=married-to, weight=0.4] 夫妻关系冷淡。

[#xingfuren.section, faction=荣国府, gender=女, generation=第三代]
== 邢夫人

贾赦继室，贾琏继母。
出身寒微，嫁入贾府后处处小心。
她为人刻薄小气，不得人心。
在抄检大观园一事上推波助澜，与 xref:王夫人[王夫人, rel=sister-in-law-rival, weight=0.5] 暗中较劲。

// 荣国府 · 第四代

[#jiabaoyu.section, faction=荣国府, gender=男, generation=第四代]
== 贾宝玉

全书核心人物，衔玉而生。
那块通灵宝玉是他的命根子，也是全书最重要的意象。
他天性聪颖，却厌恶仕途经济学问，
偏爱在内帷厮混，被贾政视为"不肖子"。

与 xref:林黛玉[林黛玉, rel=loves, weight=0.95] 的爱情是全书主线。
两人从"木石前盟"到"泪尽而亡"，写尽了有情人不得终成眷属的悲剧。
他对黛玉说过"你放心"三个字，是全书最动人的告白。

然而命运弄人，他最终娶了 xref:薛宝钗[薛宝钗, rel=married-to, weight=0.6]。
这场婚姻是 xref:王夫人[王夫人, rel=mother-of, weight=0.5] 和
xref:王熙凤[王熙凤, rel=cousin-of, weight=0.4] 合谋的"调包计"。
宝玉直到揭盖头才发现新娘不是黛玉，由此心灰意冷。

身边最亲近的丫鬟是 xref:袭人[袭人, rel=serves, weight=0.7] 和
xref:晴雯[晴雯, rel=serves, weight=0.6]。
晴雯被撵出大观园后病死，宝玉写了《芙蓉女儿诔》悼念她，
这篇祭文是全书最华彩的骈文之一。

他与 xref:贾母[贾母, rel=grandson-of, weight=0.9] 的祖孙情深，
贾母在世时是他最大的庇护。
与 xref:贾政[贾母, rel=son-of, weight=0.3] 的父子关系则充满张力。

最终，宝玉在中举之后悬崖撒手，遁入空门。
xref:贾兰[贾兰, rel=brother-of-paternal-cousin, weight=0.3] 是他侄子，
后来金榜题名，算是给贾家留了一线希望。

[#jialian.section, faction=荣国府, gender=男, generation=第四代]
== 贾琏

荣国府长房长孙，捐了个同知。
为人精明能干，却好色成性。
与 xref:王熙凤[王熙凤, rel=married-to, weight=0.5] 是"凤姐琏二爷"，
夫妻二人掌管荣国府内务。

他偷娶尤二姐为外室，被王熙凤发现后设法逼死尤二姐，
这是全书最残忍的情节之一。
贾琏对此怀恨在心，夫妻关系名存实亡。

他与 xref:贾宝玉[贾宝玉, rel=brother-of, weight=0.3] 是堂兄弟，
性格截然不同——一个务实，一个务虚。

[#wangxifeng.section, faction=荣国府, gender=女, generation=第四代]
== 王熙凤

荣国府的实际管家人，人称"凤辣子"。
xref:王夫人[王夫人, rel=niece-of, weight=0.6] 的内侄女，
xref:贾琏[贾琏, rel=married-to, weight=0.5] 的妻子。

她精明能干、八面玲珑，把偌大一个荣国府打理得井井有条。
"协理宁国府"一回最见她的才干——
秦可卿去世后她受命料理丧事，事无巨细，安排得妥妥帖帖。

但她也心狠手辣。
"弄权铁槛寺"中她收受贿赂，拆散一对有情人，逼得两条人命。
尤二姐之死更是她一手导演——
先哄骗尤二姐进府，再借秋桐之手百般折磨，最终逼其吞金自尽。

她是 xref:贾母[贾母, rel=granddaughter-in-law-of, weight=0.6] 最得力的帮手，
贾母的起居饮食都由她安排。
但贾母去世后，她失去了靠山，在府中日渐孤立。

与 xref:贾琏[贾琏, rel=married-to, weight=0.5] 的夫妻关系从恩爱走向反目。
她的判词"机关算尽太聪明，反算了卿卿性命"，
道尽了这个人物的悲剧。

[#jiayuanchun.section, faction=荣国府, gender=女, generation=第四代]
== 贾元春

贾政与王夫人的长女，入宫为妃。
省亲一回是全书最华丽的场景——
大观园就是为她省亲而建，耗资巨大。

元春在宫中并不快乐。
她说当日既送我到那不得见人的去处，
道尽了深宫寂寞。
她的死讯传来，贾府上下一片哀恸，
也预示着贾家最大的靠山轰然倒塌。

与 xref:贾宝玉[贾宝玉, rel=sister-of, weight=0.7] 兄妹情深，
宝玉的名字就是她取的。

[#jiabaochai.section, faction=荣国府, gender=男, generation=第四代]
== 贾兰

贾珠之子，李纨之子。
父亲早亡，由母亲独自抚养长大。
他勤奋好学，一心想通过科举重振家业。

与 xref:贾宝玉[贾宝玉, rel=brother-of-paternal-cousin, weight=0.3] 是堂叔侄，
性格天差地别——宝玉厌学，贾兰苦读。
最终贾兰中举，算是贾家衰败后的一缕曙光。

// 荣国府 · 丫鬟

[#xiren.section, faction=荣国府, gender=女, generation=丫鬟]
== 袭人

贾宝玉的首席丫鬟，本名花珍珠。
温柔和顺，忠心耿耿，是宝玉身边最稳重的人。
她与宝玉有肌肤之亲（"贾宝玉初试云雨情"一回），
暗中已被视为宝玉的准姨娘。

袭人深谙为人处世之道，
在王夫人面前进言，建议将宝玉搬出大观园，
得到王夫人的赏识。
但这也让她在宝玉房中的处境微妙——
xref:晴雯[晴雯, rel=rival-servant, weight=0.5] 就曾当面嘲讽她"哈巴狗"。

她最终嫁给了蒋玉菡，算是丫鬟中结局较好的。

[#qingwen.section, faction=荣国府, gender=女, generation=丫鬟]
== 晴雯

贾宝玉房中丫鬟，容貌为大观园丫鬟之冠。
性格刚烈，口齿伶俐，"撕扇子作千金一笑"是她最生动的场景。

她与 xref:袭人[袭人, rel=rival-servant, weight=0.5] 性格截然相反——
袭人柔顺，晴雯刚烈；袭人世故，晴雯天真。
王夫人嫌她"轻狂"，在抄检大观园时将她撵出。
晴雯回家后不久病死，年仅十六岁。

宝玉为她写了《芙蓉女儿诔》，
"其为质则金玉不足喻其贵，其为性则冰雪不足喻其洁"，
是全书最感人的祭文。

[#yuanyang.section, faction=荣国府, gender=女, generation=丫鬟]
== 鸳鸯

贾母的首席大丫鬟，贾母须臾离不得她。
贾赦想纳她为妾，她宁死不从，在贾母面前断发明志。
贾母去世后，她自缢殉主，是全书中最有骨气的丫鬟。

// 薛家

[#xueyiniang.section, faction=薛家, gender=女, generation=第三代]
== 薛姨妈

薛宝钗之母，王夫人的亲妹妹。
薛家是皇商，"珍珠如土金如铁"，
但到了薛姨妈这一代已经大不如前。
她带着一双儿女进京，寄居贾府梨香院。

薛姨妈性格温厚，不像姐姐王夫人那样严厉。
她对 xref:薛宝钗[薛宝钗, rel=mother-of, weight=0.9] 教养有方，
养出了一个端庄贤淑的女儿。
对 xref:薛蟠[薛蟠, rel=mother-of, weight=0.5] 则过于溺爱，
纵得他无法无天。

她与 xref:王夫人[王夫人, rel=sister-of, weight=0.7] 姐妹感情深厚，
两人心照不宣地推动"金玉良缘"。

[#xuebaochai.section, faction=薛家, gender=女, generation=第四代]
== 薛宝钗

薛姨妈之女，薛蟠之妹。
品格端方，容貌丰美，是大观园中最符合世俗标准的大家闺秀。
她佩戴金锁，上头的字与宝玉通灵宝玉上的字恰好是一对——
这就是"金玉良缘"的由来。

宝钗博学多才，诗才不在黛玉之下。
"蘅芜苑夜拟菊花题"一回中，
她与史湘云深夜商议诗题，展现了不凡的学识。
但她也有务实的一面——
她劝宝玉留心仕途经济，被宝玉当场下逐客令。

与 xref:林黛玉[林黛玉, rel=rival-in-love, weight=0.8] 的关系最耐人寻味。
两人从最初的暗中较劲，到后来的惺惺相惜，
"金兰契互剖金兰语"一回中两人推心置腹，成为知己。
最终宝钗嫁给了宝玉，却得不到他的心，
守着一个心如死灰的丈夫，同样是悲剧。

与 xref:贾宝玉[贾宝玉, rel=married-to, weight=0.6] 的婚姻是全书最大的讽刺——
得到了人，得不到心。

[#xuepan.section, faction=薛家, gender=男, generation=第四代]
== 薛蟠

薛姨妈之子，宝钗之兄。
人称"呆霸王"，是全书中最典型的纨绔子弟。
他打死冯渊，抢走香菱（甄英莲），
靠贾府的关系才摆平了官司——这就是"葫芦僧判断葫芦案"。

薛蟠粗鄙不堪，在学堂里闹出许多丑事。
但他对妹妹 xref:薛宝钗[薛宝钗, rel=brother-of, weight=0.4] 还算有几分兄妹情。
他娶了夏金桂，婚后被悍妻拿捏得死死的，
算是因果报应。

[#xiangling.section, faction=薛家, gender=女, generation=丫鬟]
== 香菱

本名甄英莲，甄士隐之女。
幼年被拐，几经辗转被薛蟠强买为妾。
她生得清秀，性情温婉，跟 xref:薛宝钗[薛宝钗, rel=serves, weight=0.5] 学诗，
"慕雅女雅集苦吟诗"一回写她痴迷诗的样子十分动人。

香菱是全书中最令人怜惜的人物之一——
从乡宦之女沦为奴婢，命运对她太不公。
她的判词"根并荷花一茎香，平生遭际实堪伤"，
道尽了她的一生。

// 林家

[#lindaiyu.section, faction=林家, gender=女, generation=第四代]
== 林黛玉

全书女主角，苏州人氏。
父亲林如海是巡盐御史，母亲贾敏是贾母最疼爱的女儿。
父母双亡后，她寄居贾府，从此再未回过故乡。

黛玉才情冠绝大观园。
"林潇湘魁夺菊花诗"一回中，
她的《咏菊》《问菊》《菊梦》三首夺魁，
连宝钗都自叹不如。
她的《葬花吟》"花谢花飞花满天，红消香断有谁怜"
是全书最脍炙人口的诗篇。

与 xref:贾宝玉[贾宝玉, rel=loves, weight=0.95] 的爱情是全书主线。
两人初见时便有"这个妹妹我曾见过的"之感——
这是"木石前盟"的前世因缘。
他们共读《西厢》、同葬落花，
在大观园的桃花树下度过了最美好的时光。

但黛玉体弱多病，又多愁善感。
她的眼泪是为还宝玉前世的灌溉之恩而来——
"欠泪的，泪已尽"，泪尽之日便是她离世之时。

xref:王夫人[王夫人, rel=disliked-by, weight=0.7] 对她不甚喜欢，
xref:薛宝钗[薛宝钗, rel=rival-in-love, weight=0.8] 是她最大的情敌。
最终在宝玉成婚之夜，黛玉焚稿断痴情，泪尽而亡。
"宝玉，宝玉，你好——"是她最后的话，未说完便咽了气。

xref:贾母[贾母, rel=granddaughter-of, weight=0.85] 是她的外祖母，
是她在贾府最大的依靠。
但贾母最终也未能成全她和宝玉。

// 史家

[#shixiangyun.section, faction=史家, gender=女, generation=第四代]
== 史湘云

贾母的侄孙女，史侯家的小姐。
自幼父母双亡，由叔叔抚养长大。
她性格豪爽，大大咧咧，是大观园中最开朗的姑娘。

"憨湘云醉眠芍药裀"是全书最美的场景之一——
她喝醉了酒，躺在石凳上睡着了，
芍药花飞了一身，蜂围蝶绕。
她还有咬舌的毛病，把"二哥哥"叫成"爱哥哥"，
宝玉听了只是笑。

她与 xref:林黛玉[林黛玉, rel=cousin, weight=0.5] 是表亲，
两人同住过一段时间，感情不错。
她也擅长作诗，与 xref:薛宝钗[薛宝钗, rel=poetry-friend, weight=0.6] 交好，
两人常一起切磋诗艺。

史湘云的结局众说纷纭，
但"因麒麟伏白首双星"暗示她后来嫁了个如意郎君。

// 大观园外

[#qinkeqing.section, faction=宁国府, gender=女, generation=第四代]
== 秦可卿

宁国府贾蓉之妻，"金陵十二钗"中最早去世的人物。
她生得袅娜纤巧，行事温柔和平，
贾母都赞她是重孙媳中第一个得意之人。

但她的身世成谜——
从养生堂抱来的弃婴，却嫁入了宁国府这样的豪门。
她的房间陈设极尽奢华，暗示着某种不寻常的来历。

秦可卿托梦王熙凤，劝她"月满则亏，水满则溢"，
要及早为家族留退路。
这番话极有远见，可惜王熙凤并未听进去。

她与公公 xref:贾珍[贾珍, rel=scandal-with, weight=0.9] 的暧昧关系
是全书中最大的丑闻之一（"秦可卿淫丧天香楼"）。
她的葬礼奢华无比，用的是义忠亲王老千岁的棺材，
暗示着背后有不可告人的秘密。

[#jiashen.section, faction=宁国府, gender=男, generation=第三代]
== 贾珍

宁国府当家人，贾敬之子。
袭了三品将军之爵，却不务正业，
整日与狐朋狗友饮酒作乐。

他与 xref:秦可卿[秦可卿, rel=scandal-with, weight=0.9] 的丑闻
是宁国府最大的污点。
秦可卿死后他"哭得泪人一般"，
超出了公公对儿媳应有的悲痛程度。

贾珍还霸占了 xref:尤二姐[尤二姐, rel=harasses, weight=0.6] 和
xref:尤三姐[尤三姐, rel=harasses, weight=0.4]，
与贾蓉父子麀聚，荒淫无度。
宁国府最终先一步被抄家，正是"箕裘颓堕皆从敬，家事消亡首罪宁"。

// 尤氏姐妹

[#youerjie.section, faction=尤家, gender=女, generation=第四代]
== 尤二姐

尤氏继母带来的女儿，容貌标致。
她先与贾珍有染，后被 xref:贾琏[贾琏, rel=concubine-of, weight=0.7] 偷娶为外室。
王熙凤得知后，将她骗入大观园，
借秋桐之手百般折磨，最终逼她吞金自尽。

尤二姐的悲剧在于她太天真——
她以为进了贾府就能安生过日子，
没想到 xref:王熙凤[rel=destroyed-by, weight=0.9] 会置她于死地。
她死时腹中还有胎儿，一尸两命。

[#yousanjie.section, faction=尤家, gender=女, generation=第四代]
== 尤三姐

尤二姐之妹，性格刚烈。
她虽然也曾与贾珍厮混，却立誓要嫁给自己看中的人。
她看中的是柳湘莲，非他不嫁。

但柳湘莲听信了关于她品行不端的传言，
上门退婚。尤三姐当场拔剑自刎，
以死明志。
"揉碎桃花红满地，玉山倾倒再难扶"——
这是全书中最惨烈的死亡场景之一。

// 金陵十二钗 · 正册之外

[#miaoyu.section, faction=大观园, gender=女, generation=出家人]
== 妙玉

栊翠庵的带发修行尼姑。
出身官宦世家，因体弱多病而出家。
她才华出众，诗才不凡，
"凹晶馆联诗悲寂寞"一回中与黛玉、湘云联诗，
写出了"寒塘渡鹤影，冷月葬花魂"的千古名句。

妙玉孤傲清高，连刘姥姥用过的茶杯她都嫌脏要扔掉。
但她的结局却是全书中最悲惨的——
"可怜金玉质，终陷淖泥中"，
暗示她最终沦落风尘。

// 刘姥姥

[#liulaolao.section, faction=乡野, gender=女, generation=老一辈]
== 刘姥姥

乡下老妪，与贾府八竿子打不着的远亲。
她三进荣国府，是全书结构上最重要的线索人物。

一进荣国府时她小心翼翼，打秋风求接济。
二进荣国府时她装疯卖傻，逗得贾母开怀大笑——
"刘姥姥进大观园"的典故就出于此。
三进荣国府时贾府已经败落，
她仗义营救了 xref:巧姐[巧姐, rel=rescues, weight=0.9]，
报答了当年的恩情。

刘姥姥看似粗鄙，实则大智若愚。
她的存在，是对贾府奢靡生活最辛辣的对照。

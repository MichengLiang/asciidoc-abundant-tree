= 基础 RDF 投影示例

这个示例展示 RDF12 heading projection 的基础查询面：标题树、地址标签、直接属性、交叉引用边证据和本地 target 归属。

== 库存校验

库存校验规则描述订单进入履约前需要读取的库存快照。

[#stock-query-example]
[source,sql]
----
SELECT sku, available_qty
FROM inventory_snapshot
WHERE order_id = :order_id;
----

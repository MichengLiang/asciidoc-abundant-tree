== 交叉引用边

交叉引用边由标题切片中的 xref 创建。行内解析只需要识别交叉引用，因为交叉引用是非层级边的来源。

=== Source Heading

xref 所在的标题切片决定边的 source heading。

[source,asciidoc]
----
配送策略依赖 xref:capacity[运力规则, rel=depends-on, weight=0.8, relation-evidence=rel-delivery-capacity]。
----

该 xref 位于 `配送策略` 标题切片中，因此 source heading 是 `配送策略`。

=== Target Heading

xref 的 selector 由解析器给出：作者写下的目标在那个位置的属性取值下展开属性引用，再按官方规则切去 `#` 之前的文档部分（解析器规约第 8 章 Xref Occurrence）。selector 在标题投影 label 空间中按整串相等绑定；label 空间由地址路径、`aat:addressLabel` 与 `aat:generatedAddressLabel` 构成（xref:地址与 Label 空间[地址与 Label 空间]）。`+xref:红烧肉::火候[]+` 的 selector 是 `红烧肉::火候`，绑定到红烧肉下的那一节火候。selector 不绑定到 role、字段谓词、xref display label、raw 文本或标题节点 IRI。

指向别的文档的 xref 不在本文档的 label space 里绑定：边证据写 `aat:targetDocument`（文档部分）与 `aat:targetSelector`（片段），由读得到那份文档的消费者去绑定。

`aat:addressLabel` 来自标题自身手动 ID，或来自归属到标题的本地非标题 target ID。selector 指向 listing、table、block、inline anchor 或 source value block 的本地 target ID 时，target heading 是该 target ID 所属的标题节点。

`capacity` 绑定到 address label 为 `capacity` 的标题节点。因此上例的 target heading 是 `运力规则`。

`engine-code` 是 `核心引擎设计` 标题切片内 listing block 的本地 target ID 时，xref target selector `engine-code` 绑定到 `核心引擎设计` 标题节点。relation triple 的 object 是标题节点，不是 listing block。

selector 未绑定时，边证据保留 `aat:targetSelector` 和回源坐标，不生成虚构 target heading，不生成主 relation triple。

selector 有多个拥有者时，每个拥有者都是这处 xref 的 target heading：边证据为每个拥有者写一条 `aat:targetHeading`，图里为每个拥有者断言一条主 relation triple，同一个边证据以 `rdf:reifies` 指向全部这些三元组项。投影器不判断这是不是歧义，也不挑其中一个。

一处引用指向一节还是几节，由书的约定规定，在下游检查（例如工作区的书架检查把一处多指报为错误）。下游从图上自己数：一个边证据有几条 `aat:targetHeading`（第 7 章「查找一处多指的交叉引用边」）。一个 reifier 可以 reify 多个三元组项（RDF 1.2 Concepts §1.5），所以“同一处引用”在图里仍是一个资源。

xref edge evidence 保留 selector 和官方解析事实。`aat:targetSelector` 保存绑定用的 selector，作者写下的原样在 `aat:raw` 里；`aat:officialResolvedId`、`aat:officialResolvedType` 和 `aat:officialHref` 保存 Asciidoctor 解析出的 target id、target type 和 href。官方解析事实不改变 relation triple 的 heading endpoint。

[source,turtle]
----
:heading-2 aat:references :heading-3 , :heading-5 .

:xref-edge-l12-c4-o0 a aat:XrefEdge ;
  rdf:reifies <<( :heading-2 aat:references :heading-3 )>> ,
              <<( :heading-2 aat:references :heading-5 )>> ;
  aat:sourceHeading :heading-2 ;
  aat:targetSelector "重复标题" ;
  aat:targetHeading :heading-3 , :heading-5 ;
  aat:relativePath "samples/ambiguous.adoc" ;
  aat:startLine 12 ;
  aat:endLine 12 .
----

=== Predicate

predicate 由 xref attribute `rel` 决定。没有 `rel` 时，predicate 是 `aat:references`。有 `rel` 时，predicate 使用该字段映射出的关系 IRI。

示例：

[source,asciidoc]
----
xref:capacity[运力规则]
----

投影为：

[source,turtle]
----
:source-heading aat:references :target-heading .
----

示例：

[source,asciidoc]
----
xref:capacity[运力规则, rel=depends-on]
----

投影为：

[source,turtle]
----
:source-heading rel:depends-on :target-heading .
----

`rel` 只选择谓词。投影器不解释该谓词的业务语义。

`rel` 字段是绝对 IRI 时，predicate 使用该 IRI。`rel` 字段是已知 CURIE 时，predicate 使用展开后的 IRI。其余非空的 `rel` 是书的关系谓词词表里的词，predicate 是 `rel:` 下按原文写成的名字，转写规则见 xref:名字进入 IRI[名字进入 IRI]：`rel=depends-on` 映射为 `rel:depends-on`，`rel=依据` 映射为 `rel:依据`。`rel` 为空时，边证据保留 `aat:rel`，不生成主 relation triple。

=== 边证据

交叉引用边证据保存该边在源文档中的出现点、字段和 official resolved facts。边证据不是标题节点。

边证据 IRI 使用 `xref-edge-l<startLine>-c<startColumn>-o<ordinal>` local id。`startLine` 和 `startColumn` 来自 xref occurrence 的起点。相同行列出现多个 xref 时，`ordinal` 按源文档顺序从 `0` 递增；无冲突时使用 `0`。

边证据的 `aat:startColumn` 与 `aat:endColumn` 使用 source span column 语义。列号是 1-based Unicode code point column；`aat:startColumn` 是 xref occurrence 的起始列，`aat:endColumn` 是 xref occurrence 结束后的列位置。

示例：

[source,turtle]
----
:heading-2 rel:depends-on :heading-3 .

:xref-edge-l8-c8-o0 a aat:XrefEdge ;
  rdf:reifies <<( :heading-2 rel:depends-on :heading-3 )>> ;
  aat:sourceHeading :heading-2 ;
  aat:targetHeading :heading-3 ;
  aat:targetSelector "capacity" ;
  aat:displayLabel "运力规则" ;
  aat:rel "depends-on" ;
  field:weight "0.8" ;
  field:relation-evidence :value-l25-o0 ;
  aat:raw "xref:capacity[运力规则, rel=depends-on, weight=0.8, relation-evidence=rel-delivery-capacity]" ;
  aat:relativePath "samples/structural-payload.adoc" ;
  aat:startLine 8 ;
  aat:endLine 8 ;
  aat:startColumn 8 ;
  aat:endColumn 96 .
----

普通 xref named attributes 投影为字段谓词，规则见 xref:Field Predicate[Field Predicate]。示例中的 `weight=0.8` 投影为 `field:weight "0.8"`。字段值按源文档表面值保存为 string literal。

xref edge complex property 也使用 field predicate。示例中的 `relation-evidence=rel-delivery-capacity` 匹配 source value block id 时，边证据输出 `field:relation-evidence :value-l25-o0`。raw value object 保存该 source value block 的 raw、format、source coordinates 和 `aat:sourceValueId`。

同一个 xref edge evidence 可以拥有多个 complex properties。每个 xref named attribute 的 key 是字段名；value 匹配 source value block id 时，每个匹配的 block 各给出一个 raw value object 字段值（第 6 章「Xref Edge Complex Property」）。未匹配时，该字段值是 string literal。

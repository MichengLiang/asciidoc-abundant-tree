= RDF 1.2 投影词表速查

[cols="1,2", options="header"]
|===
|谓词或类型 |含义

|`aat:Heading`
|标题节点类型。

|`aat:XrefEdge`
|交叉引用边证据类型。

|`aat:FieldEvidence`
|字段证据类型：每个标题字段一个，reify 那条字段三元组。

|`aat:AsciiDocSourceDocument`
|源文档 provenance resource。

|`aat:SourceFile`
|book-entry source set 中的源文件重建资源。

|`aat:headline`
|标题文本。

|`aat:addressPath`
|两段以上的地址路径（`红烧肉::火候`），每个后缀一条。与 `aat:headline`、`aat:addressLabel`、`aat:generatedAddressLabel` 一起构成 heading label space。

|`aat:addressLabel`
|可寻址到 heading node 的作者声明 label 或本地 target alias。

|`aat:generatedAddressLabel`
|投影器恢复的 generated label。

|`aat:role`
|标题身份字段。

|`aat:containsDirectly`
|heading node 之间的直接父子结构边。

|`aat:childOrder`
|同一 parent 的 direct children 中的 1-based 局部顺序。

|`aat:documentOrder`
|logical heading tree preorder 的 1-based 全局顺序。

|`aat:raw`
|heading slice 或 raw value object 的源文本。

|`aat:relativePath`
|相对于 document root 的源文件路径。

|`aat:startLine` / `aat:endLine`
|源文件闭区间行范围。

|`aat:headingLine`
|标题行。

|`aat:sourceHeading`
|xref edge evidence 的 source heading。

|`aat:targetHeading`
|xref edge evidence 的 target heading：selector 在 label space 里的每个拥有者各一条。

|`aat:targetSelector`
|xref 源表面写出的 selector。

|`aat:format`
|raw value object 的 source block language。

|`aat:forSelector`
|heading complex property 的 selector binding 证据。

|`aat:sourceValueId`
|xref edge complex property 的 source value id binding 证据。

|`aat:fieldName`
|字段证据上作者写下的字段名原文；字段谓词是它的转写。

|`aat:surface`
|字段写在哪种表面：`attrlist`、`description-list`、`heading-inline`。

|`aat:fieldOrder`
|字段在所属标题内的 0-based 源顺序：先 attrlist，再描述列表，再 `hmeta:` 宏。

|`rdf:reifies`
|RDF 1.2 reifier 指向 triple term：一处 xref 有几个 target heading，它的边证据就 reify 几个 relation triple；字段证据 reify 一条字段三元组。
|===

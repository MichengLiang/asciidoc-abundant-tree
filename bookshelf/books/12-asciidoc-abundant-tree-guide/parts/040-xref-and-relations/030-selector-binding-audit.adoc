== Selector Binding 与审计

xref target selector 查询 heading label space。命中几个 heading node，projection 就为每个输出一条 `aat:targetHeading` 和一条主 relation triple，同一个 edge evidence reify 全部这些 relation。未命中时，edge evidence 保留 selector 和回源坐标，没有 target heading。

未绑定和一处引用指向多个 heading node 都是源文档事实。projection 不判断它们算不算错；下游 lint 根据项目约定判断（例如工作区的书架检查把一处多指报为错误），从图上数一个 edge evidence 有几条 `aat:targetHeading` 即可。审计报告必须带 source coordinate，使作者或 agent 能回到 xref 出现点。

未绑定 selector 查询：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?edge ?selector ?path ?line WHERE {
  ?edge a aat:XrefEdge ;
        aat:targetSelector ?selector ;
        aat:relativePath ?path ;
        aat:startLine ?line .
  FILTER NOT EXISTS { ?edge aat:targetHeading ?target . }
}
----

一处多指查询：

[source,sparql]
----
PREFIX aat: <https://micheng.dev/ns/asciidoc-abundant-tree#>

SELECT ?edge ?selector (COUNT(?target) AS ?targets) WHERE {
  ?edge a aat:XrefEdge ;
        aat:targetSelector ?selector ;
        aat:targetHeading ?target .
}
GROUP BY ?edge ?selector
HAVING (COUNT(?target) > 1)
----

selector audit 的输出不是另一个事实来源。它是 projection facts 的维护视图。报告记录 `kind`、`selector`、`relativePath`、`line` 和 target heading；修订动作仍然发生在源书稿中。
